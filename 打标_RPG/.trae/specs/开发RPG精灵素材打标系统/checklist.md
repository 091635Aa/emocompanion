# Checklist

- [ ] 项目骨架与配置：目录树 + `配置\系统配置.json` + 初始化模块按规格创建
- [ ] 素材规格表：包含 MV/MZ 的 characters / faces / tilesets（A1-A5、B-E）/ sv_actors / sv_enemies，尺寸与布局符合 spec 调研表，支持自动识别与手动覆盖
- [ ] 素材分割：能按规格把整图切成单格 PNG，坐标清单正确，空块跳过，支持断点续切
- [ ] 提示词与解析：图片打标 JSON schema 完整，解析失败自动重试
- [ ] 推理引擎：能连接 v1.0 的 30B llama-server（127.0.0.1:8766）以图片输入返回结构化 JSON；服务不可用给出明确提示
- [ ] 打标流水线：进度 + 断点续打 + 并行（默认 2）+ 失败重试（3 次）与失败归档
- [ ] 向量索引：本地嵌入模型生成向量写入 ChromaDB，可全量重建与增量追加
- [ ] MCP 服务：四个工具可用，search 返回紧凑一行式结果，get_asset 返回完整详情
- [ ] CLI：search / detail / list / stats 子命令可用，输出格式与 MCP 一致
- [ ] 汇总报告：JSON + HTML 报告生成，含素材数、类型分布、成功率、失败/未识别清单、向量库统计
- [ ] 端到端自测：样例 PNG 走通 分割 → 打标 → 索引 → 查询 全链路
