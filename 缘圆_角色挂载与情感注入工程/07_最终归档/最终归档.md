## 二、里程碑成果（按时间线）

### M0 基线评估（8GB 正式评估）
- Qwen3-4B(4bit) / DeepSeek-Qwen7B(4bit) vs Qwen3-8B 裁判（错开）
- 结论：instruct+人设提示已把保真拉到 86-92；P3 注入收益在"防复读/防塌缩/细腻度"，非人格主载体
- 稳态显存：4B=4.53G（8GB 档达标）、7B=8.33G（偏紧）
- 交付：`05_三档显存测试/8GB正式评估报告.md`

### M1 骨架+指纹（L1 去AI腔）
- 数据驱动词袋：6935 条真实口播 / 112 万字符 → 36 正例项 + 66 空泛词抑制项
- mild 双向抑制：去AI腔 71→74（+3，两次复现一致）；strong 有害（否决）
- 关键工程：多字短语只做续接抑制（不压首 token），关闭 Qwen3 thinking 块
- 交付：`deai_opt.py` + `deai_bag.json` + 去AI腔双向抑制_实验报告.md

### M2 方向层（L2 P3 锚点升级）
- 对比提示提取 v_角色（正："温柔撒娇喵主播圆圆" / 负："理性正式主播"）
- 层扫描：Qwen3-4B 最优注入层 **L35**（36 层模型，不可照搬文献 L20）
- 情绪起伏 +2（81→83）、重复率 0.118 最低、综合 85 不退化
- β 标定：4B 全区间稳定（主推 β1.0）；7B 封顶 β1.0（1.4 回退）
- 交付：`p3_contrast.py` + `p15_sweep.py` + 对应实验报告

### M3 双通道（P4/P5）—— 诚实负结果
- P4 KV共振 + P5 DSA 内心态 实装跑通（适配 transformers 5.14）
- P4@κ0.3 反而熵↓重复↑，**不过边际增益门** → 暂不启用，降级可选调参
- 结论：通道必须配对、强度预算封顶（写入工程铁律）
- 交付：`p45_dual.py` + P4_P5双通道_实验报告.md

### M4 推理框架提速（最新成果）
- **旧栈**：transformers + BitsAndBytes 4bit（decode 10 tok/s）
- **新栈**：llama.cpp CUDA + Q4_K_M GGUF（decode 27.3~33.8 tok/s）
- **提速 +173%~238%，加载 -98.5%（259.9s→2.2s），进程内存 2.8GB**
- 踩坑：Zen3 CPU 的 AVX-512 崩溃（0xc000001d）→ 动态后端 wheel（GGML_CPU_ALL_VARIANTS）
- 交付：`推理框架提速验证报告.md` + `bench_framework.py`

## 三、最终架构：分层解耦 × 协同调度

```
用户输入 ──▶ 调度器 ──▶ 每步解码
  L0 骨架层    人设提示段 + 身份锁定          (提示空间)
  L1 指纹层    去AI腔 mild 双向抑制            (logits+频率)
  L2 方向层    P3 锚点注入 β·tanh(S·v/T)      (logits)
  L3 共振层    P4 KV 缩放（暂不启用）           (KV)
  L4 内心态层  P5 DSA（暂不启用）               (hidden态)
  L5 兜底层    OQC 熵/重复率/身份泄漏监控      (兜底)
```

**工程铁律**（从实测提炼）：
1. 每个算法有最优强度窗，超窗即劣化（强β有害、strong去AI腔有害）
2. 通道必须配对，禁止单开（P4 单通道有害）
3. 分层正交空间（词频/logits方向/KV/状态向量）+ 全局 logits 扰动预算 ≤2.5
4. 边际增益门：每层 ablation 证明净正才并入

## 六、部署与运维

### 6.1 一键启动（最终归档入口）
```bash
cd 07_最终归档
python app.py                          # 交互菜单
python app.py --serve --port 8000      # 启动服务
python app.py --chat "你好呀"           # CLI 对话
python app.py --list                   # 扫描模型/扩展包
```

### 6.2 CLI 交互工具（多请求格式）
```bash
python cli.py chat "你好呀"                     # 引号
python cli.py chat 晚上好呀 今天开心吗           # 空格分隔
python cli.py chat '{"messages":[...]}'         # JSON
python cli.py chat -i                           # 交互模式
python cli.py chat -m Qwen3-4B-Q4_K_M -p default "hi"   # 定向模型+扩展包
python cli.py serve -m Qwen3-4B-Q4_K_M -p default        # 定向服务
```

## 八、遗留事项与后续建议

1. **EmoScore 正式验收**：当前简易规则评分 +4.5（1.05×）；需接入 Qwen3-8B 五维裁判盲评（`eval_emoscore.py` 管线已就绪）
2. **P4/P5 复评**：κ∈{0.1,0.15} 小范围扫描过边际增益门后复评
3. **多角色扩展**：`role_pack_{name}.json` 自动发现已支持，可制作更多角色
4. **流式输出**：降低首包延迟（当前 64tok 约 4.2s）
5. **KV cache 量化**：进一步降显存，支持更长上下文
6. **释放 RVC 进程**：当前后台占用显存导致部分卸载，释放后稳定 33+ tok/s
