# 调用测试方法

> 三个服务入口：① 文本引擎（backend/server.py）② TTS 统一服务（unified_server.py）③ 文本+语音一体化（integrated_app.py）。默认端口见各节，均可 `--port` 覆盖。

---

## 0. 环境准备

- Python 3.10（各入口会自动创建/激活 .venv，pip 用清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`）
- NVIDIA GPU + CUDA 12.x（实测 RTX 3080 Laptop 16GB；兼容 20/30/40/50 系及 AMD）
- llama.cpp 二进制：`llama-server.exe`（文本引擎）、`llama-tts.exe`（语音），不在仓库内
- 模型文件（英文目录存放，避免路径解析问题）：
  - `Qwen3-4B-Q4_K_M.gguf` —— 文本引擎
  - Qwen3-TTS base GGUF + mmproj
  - `voice_lora_qwen3tts.gguf` / `emotion_lora_qwen3tts.gguf`（可选 `style_lora_qwen3tts.gguf`）
  - speaker 参考音频 `503_519_520_137_010.wav`（TTS 必须，去掉声音不像）

## 1. 文本引擎（POST /chat）

```bash
cd EmoCompanion_角色挂载与情感注入工程/04_源码与原型/backend
python app.py                      # 一键启动（venv+依赖+服务），默认 http://127.0.0.1:8000

# 或最终归档入口
cd ../../07_最终归档 && python app.py --serve --port 8000

# CLI 直测（不起服务）
python cli.py chat "你好呀"
python cli.py chat -i                                      # 交互多轮
python cli.py chat -m Qwen3-4B-Q4_K_M -p default "你好呀"   # 定向模型+角色包
```

### 对话

```bash
curl -X POST http://127.0.0.1:8000/chat -H "Content-Type: application/json" -d '{
  "messages": [{"role":"user","content":"晚上好呀，今天直播好多人来，我好开心，你呢？"}],
  "max_new": 128, "temperature": 0.9, "use_layers": true, "role": "default"
}'
```

响应含 `reply` / `usage` / `latency_s` / `tok_s`。`use_layers=false` 可得裸模型输出做 A/B 对照。

### 其他端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/chat` | POST | 多轮对话，三层注入开关、角色、seed |
| `/roles` | GET | 列出角色包 |
| `/roles/{name}` | POST | 热切换角色包（`data/role_pack/role_pack_{name}.json` 放入即自动发现） |
| `/health` | GET | 显存/进程内存/统计/当前角色 |
| `/stats` | GET | calls/tokens/avg_tok_s |

### Python 示例

```python
import requests
r = requests.post("http://127.0.0.1:8000/chat", json={
    "messages": [{"role": "user", "content": "今天有点累，陪我聊聊"}],
    "use_layers": True})
print(r.json()["reply"])
```

## 2. TTS 统一服务（unified_server.py）

```bash
cd EmoCompanion_角色挂载与情感注入工程/06_Qwen3TTS外挂/serve
python unified_server.py           # 默认端口见脚本头部参数
```

### 合成

```bash
curl -X POST http://127.0.0.1:<port>/api/tts/synthesize -H "Content-Type: application/json" -d '{
  "text": "今天真的好开心呀，想跟你分享好多事情！",
  "emotion": "开心", "backend": "gguf", "adapter": "emotion",
  "temperature": 0.85, "top_k": 60, "rate": 1.0, "seed": 42
}' --output out.wav
```

返回 `audio/wav`（24kHz mono），响应头 `X-TTS-Meta` 带 JSON 元信息（mode/audio_seconds/backend）。参数全表见 `unified_server.py` 的 `TTSReq`：`text/emotion/backend/seed/temperature/top_k/rate`。

### 情感识别与管线

```bash
# 情感自动识别（文本引擎在线走 LLM，离线走词典；user_msg 提供用户语境优先判定用户真实情绪）
curl -X POST http://127.0.0.1:<port>/api/tts/detect -H "Content-Type: application/json" \
     -d '{"text":"唉，今天被老板骂了，好难受","user_msg":"我刚被老板骂了"}'

# 文本→情感→TTS 全管线
curl -X POST http://127.0.0.1:<port>/api/pipeline/talk -H "Content-Type: application/json" \
     -d '{"messages":[{"role":"user","content":"期末考试考砸了…"}],"auto_emotion":true}'

# 健康检查
curl http://127.0.0.1:<port>/api/tts/health
```

## 3. 一体化服务（integrated_app.py，推荐验收入口）

```bash
cd EmoCompanion_角色挂载与情感注入工程/06_Qwen3TTS外挂/serve
python integrated_app.py           # 文本引擎 + TTS + Web 前端
# 浏览器打开 http://127.0.0.1:8000/ 即是聊天界面（web/app.js）
```

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/health` | GET | text_engine / tts / gguf / mount / load 状态 |
| `/api/mounts` | GET | 当前挂载 + 可选 emotions / speaking_styles / adapters |
| `/api/mounts` | POST | 切换挂载（MountReq：adapter/emotion/emotion_mode/style/role/want_tts…） |
| `/api/quick` | GET | 前端快速问法动态下发 |
| `/api/sessions` | GET/POST | 会话列表/新建（SQLite 持久化） |
| `/api/sessions/{sid}` | GET/DELETE | 会话详情（含历史音频 URL）/删除 |
| `/api/sessions/{sid}/talk` | POST | 对话主端点（TalkReq，见下） |
| `/api/sessions/{sid}/stream` | POST | SSE 流式 |
| `/api/tts/synthesize` | POST | TTSReq：text/emotion/backend/adapter/rate |
| `/api/tts/detect` | POST | DetectReq：text/user_msg |
| `/audio/{fname}` | GET | 音频回放 |

### TalkReq（对话主请求）

```json
{
  "content": "今天考砸了，好难过…",
  "want_tts": true,
  "emotion_mode": "auto",          // auto=自动识别 | 手动指定 emotion
  "emotion": "温柔",
  "style": "温柔",                  // StylePlug 八风格之一
  "role": "default", "adapter": "emotion",
  "max_new": 128, "temperature": 0.9, "top_p": 0.9, "top_k": 50,
  "tone_variation": 0.3
}
```

### curl 冒烟测试序列

```bash
B=http://127.0.0.1:8000
curl $B/api/health
curl $B/api/mounts
curl -X POST $B/api/sessions -H "Content-Type: application/json" -d '{}'
SID=<上一步返回的 id>
curl -X POST $B/api/sessions/$SID/talk -H "Content-Type: application/json" \
     -d '{"content":"晚上好呀，今天好开心！","want_tts":true,"style":"元气"}'
```

## 5. 已知坑位（调测必读）

- llama-cpp-python 用 JamePeng fork（官方 AVX-512 wheel 在 Zen3 崩溃 0xc000001d）
- llama-tts 的 `--lora` 只接受 GGUF LoRA（safetensors 报 `expected 'GGUF'`）；`--lora-scaled` 因 Windows 盘符冒号不可用，用 `--lora f1,f2` 等权
- 文本标签（`（语速加快…）`）会被 Base 模型朗读出来，禁止注入 TTS 文本
- 逐句合成必须固定 seed 序列 + speaker=503，否则音色漂移
- jsonl 读取用 `encoding='utf-8-sig'`（BOM 坑）
