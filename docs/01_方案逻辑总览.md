## 一、总体架构：文本引擎六层注入（L0-L5）

代码位置：`EmoCompanion_角色挂载与情感注入工程/04_源码与原型/backend/engine.py`

```
用户输入 ──▶ 调度器 ──▶ 每步解码
  L0 骨架层    人设提示段 + 身份锁定           (提示空间)
  L1 指纹层    去AI腔 mild 双向抑制             (logits + 频率)
  L2 方向层    P3 锚点注入 β·tanh(S·v/T)       (logits, 预计算 151936 维 bias)
  L3 共振层    P4 KV 缩放（实测不过门，暂不启用） (KV)
  L4 内心态层  P5 DSA（暂不启用）                (hidden 态)
  L5 兜底层    OQC 熵/重复率/身份泄漏监控       (兜底)
```

**工程铁律**（实测提炼，写入引擎）：

1. 每个算法有最优强度窗，超窗即劣化（强 β 有害、strong 去AI腔有害）
2. 通道必须配对，禁止单开（P4 单通道有害）
3. 分层正交空间（词频/logits 方向/KV/状态向量）+ 全局 logits 扰动预算 ≤2.5
4. 边际增益门：每层 ablation 证明净正才并入

**角色包机制**（≤10MB 热切换）：`role_pack_{name}.json` = 人设提示段 + v_角色（对比提取）+ 示例库 + 身份拦截句库 + 正例词袋 + 空泛抑制表 + p3_bias（151936 维 npy）。切换 = 指针替换，无权重加载、无重打标。

## 三、推理栈收敛：transformers → llama.cpp GGUF

- **旧栈**：transformers + BitsAndBytes 4bit → decode 10 tok/s、加载 259.9s
- **新栈**：llama.cpp CUDA + Q4_K_M GGUF → decode 27.3~33.8 tok/s、加载 2.2s（-98.5%）
- 关键坑：Zen3 CPU AVX-512 崩溃（0xc000001d）→ JamePeng fork 动态 CPU 变体 wheel（GGML_CPU_ALL_VARIANTS）
- 推理提速靠**减少调用次数**：整段一次合成为主，长回复才拆关键子句（上限 3 次）
- `-c 2048` 显式小上下文压 KV 缓存；`-ngl 99` 全量上 GPU，显存恒 ~3.5GB

## 四、Qwen3-TTS 语音外挂（StylePlug 架构）

代码位置：`EmoCompanion_角色挂载与情感注入工程/06_Qwen3TTS外挂/serve/`

```
文本回复 ─▶ strip_control_tokens 剥标记 ─▶ compose_params(情感,风格) ─▶ llama-tts.exe
             │                              │
             │ shape_for_style: 标点密度塑形节奏  │ 情感→采样参数映射（开心→temp0.85/top_k60 …）
             ▼                              ▼
        [风格] 标记驱动表达            --lora voice,emotion(,style) 三个 GGUF adapter
                                       + --tts-speaker-file 503_519_520_137_010.wav 锚定音色
```

正交可控三轴：

1. **情感（emotion）**：LoRA adapter + 情感→采样参数映射
2. **说话风格（style）**：`STYLE_PRESETS` 8 种（自然/甜美/元气/活力/娇俏/温柔/慵懒/坚定），采样层叠加 + 标点塑形；可选第三外挂位 style LoRA
3. **语速（rate）**：模型原生变速；显式指定才用带相位传播的 `_time_stretch`（禁用裸 FFT 相位声码——电音元凶）

**合成策略**：整段一次合成（`paragraph_once`）为主；仅长回复（>24 字+含逗号+≥2 种情感）拆关键子句（`_merge_clauses` 上限 3 次调用），稳定 seed 序列（base+i*7）+固定 speaker=503 保证音色一致；逐句合并前 `_trim_silence` 裁静音。

**训练线**：`finetuning_official/`（sft_lora.py 音色 / sft_style_lora.py 风格，双路径=音色训练+情感训练，不做传统标注训练）；`scripts/hf_lora_to_tts_gguf.py` 把 HF PEFT LoRA 转 GGUF LoRA（tensor 名映射 q_proj→attn_q 等）；`serve/calibration/` 校准框架（生成→参照原始音频修正→评分→权重优化，可回档 checkpoint）。
