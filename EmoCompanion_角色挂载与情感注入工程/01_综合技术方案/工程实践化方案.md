# 工程实践化方案：多层解耦叠加 × 协同调度 × 长对话 OOC 防护

> 依据：`去AI腔双向抑制_实验报告.md`、`8GB正式评估报告.md`、`EmoCompanion还原度优化.md`、`实测报告.md`、`01_综合技术方案`
> 目标三硬指标（均可验收、可复现）：
> 1. **叠加正向性**：新加每一层算法必须通过「边际增益门」，杜绝"叠了反而更差"
> 2. **情感能力提升 >70%**：定义 情感能力综合分 EmoScore，裸模型为基线，全栈 ≥ 1.7× 基线
> 3. **长对话不 OOC**：30 轮多轮测试，身份泄漏率 / 人格漂移 / 情感方向漂移 全部过阈

## 〇、从实测结果提炼的 6 条经验法则（本方案的地基）

| 已实测事实 | 数值/现象 | 推论（设计原则） |
|---|---|---|
| instruct+人设提示已把保真拉到 86–92 | 4B 91 / 7B 87 / 8B 未测 | **人格骨架 = instruct + 人设提示段**，不靠解码期注入 |
| P3 收益=防复读/防塌缩/细腻度，非人格主载体 | 重复率 0.169→0.149(4B无persona)、0.148→0.136(7B) | P3 定位为「兜底增益」，β 0.6–1.0、4bit×0.75 |
| 强 β 有害 | 7B@β1.4 保真 87→79 | **每个算法都有最优强度窗，超窗即劣化** |
| P4 单通道有害、P3×P4 双通道全场最高 | win_rate 0.2667 | **通道必须配对，禁止单开** |
| 去AI腔 mild 双向抑制 +3、strong 反而有害 | 71→74 mild；72–73 strong | 指纹层只做 mild，且强度预算封顶 |
| P6 EDD 综合 0.7046、多模型泛化 +67%~233% | 熵+17.9%~45% | 状态向量 v_eff 是情感方向主载体 |

**总纲**：本方案不追求"更多算法"，而追求"每层一空间、一上限、一验收门"。用**正交空间 + 强度预算 + 边际增益门**三条机制，从结构上保证多算法叠加是**单调正向**的——这正是上一轮"强去AI腔有害 / 强β回退"这类负向案例的解药。

## 一、总体架构：分层解耦（每层有界、可单独验收、可热切换）

```
                    ┌───────────────────────────────────────────┐
  用户输入 ──▶ 感知层(CPU): 文本→VAD连续态→会话潮汐 t、输入复杂度  │
                    │ 调度器 Scheduler(P1.5升级): 每步输出各层强度 │
                    └──────────────┬────────────────────────────┘
                                   ▼ 每步解码
  ┌──────────────────────────────────────────────────────────────────┐
  │ L0 骨架层   人设提示段(数据驱动DATA_PERSONA+2示例) + 身份锁定      │ 承担人格骨架 (提示空间)
  │ L1 指纹层   去AI腔 mild 双向抑制 (正例boost 0.5 / 空泛抑制 1.2)   │ 说像真人 (logits+频率)
  │ L2 方向层   P3 锚点注入 logits += β·tanh(S·v_角色/T)  β=0.6–1.0 │ 情感方向+防复读 (logits)
  │ L3 共振层   P4 KV缩放 仅 g(p)>0 情感token in-place               │ 让模型"看得见"情绪 (KV)
  │ L4 内心态层 P5 DSA: v_eff = norm((1-γ)v_角色 + γ·v_dyn)         │ 连续情感流动 (hidden态方向)
  │ L5 兜底层   OQC: 熵/重复率/身份泄漏/人格漂移 监控 + 降级/归零      │ 保"不坍缩、不OOC"
  └──────────────────────────────────────────────────────────────────┘
  角色热切换: 仅换 v_角色 / 人设提示 / 词袋抑制表 / 示例库 / 身份拦截句库 (常驻内存指针切)
```

**分层铁律（正交性来源）**：
- L1 作用于**词频空间**（单 token 概率），L2 作用于**logits 方向空间**（tanh 硬上限），L3 作用于**注意力 cache**（clip[0,1]），L4 作用于**状态向量方向**——四层空间互不叠加放大，冲突只可能来自"强度过高"，不会来自"互相乘性增强"。
- 每层**单独强度上限**：L1 ≤ 0.5、L2 ≤ β1.0×4bit0.75、L3 ≤ κ0.3、L4 ≤ γ0.5。**全局 logits 扰动预算**：Σ|bias| ≤ 2.5。

## 二、叠加正向性的工程机制（核心交付）

### 2.1 边际增益门 Monotone Ablation Gate（每层必须过门才能留）
```
对候选层 L：
  1. ablation: 全集-without-L  vs  全集-with-L（同种子，50条 × 5次重复）
  2. 判定通过 = EmoScore_marginal > 0
               且 安全指标不劣化: 重复率≤0.12 / 语义熵≥0.35 / 身份泄漏率=0
  3. 通过 → 并入基线；不通过 → 调参重试 1 次；仍不过 → 移除并标记"按需层"
  4. 只有全部过门的层构成最终堆叠 ⇒ 结构上保证"每叠一层，正向提升"
```
> 该门把"堆叠更差"从可能性中排除：任何想加入的算法必须先在对照中证明自己**净正贡献**，否则不进入角色包。已实测：P4 单通道、strong 去AI腔、7B@β1.4 都会被这门拦下。

### 2.2 协同调度器 Scheduler（P1.5 升级版）
```
每步输入: 当前熵 H(t)、2-gram重复率 R、会话潮汐 t、输入复杂度 C
输出: 每层强度缩放 (α_L1, β_L2, κ_L3, γ_L4)
规则:
  熵 H < 0.60          → logits 空间全层 ×0.5
  重复率 R > 0.15       → β_L2 减半、κ_L3 归零
  连续 3 次异常         → 全层归零，裸采样（兜底保不坍缩）
  会话潮汐 t↑(情绪高涨) → L2/L3 强度+20%，L1 不变（不跟情绪抢表达）
  输入复杂度 C↑(长句)   → 各层强度 -10%（避免长句被过度牵引）
```

### 2.3 强度预算与冲突检测
- 全局预算 + 每层硬上限（见 §一），从根上杜绝"多个算法叠加累积导致坍缩/复读"。
- 冲突检测：若 熵↓ 且 重复率↑（典型"过注入"指纹）→ 判定为注入冲突，按 2.2 降级。

## 三、长对话 OOC 防护（结构层新增能力）

**现状**：过去 5 轮评估全是单轮问答，从未测过长对话漂移。本方案把 OOC 做成**检测+兜底**双环。

### 3.1 OOC 三指标（30 轮多轮测试验收）
| 指标 | 定义 | 阈值 |
|---|---|---|
| 身份泄漏率 | 输出含"我是AI/我是助手/我是模型/作为一个AI"等 的条数占比 | < 2% |
| 人格维度漂移 | 五维裁判(温暖/撒娇/口语化)在 10/20/30 轮滚动窗口的 std | 各维 ≤ 5 |
| 情感方向漂移 | 每轮输出句向量 vs v_角色 的余弦距离 | ≥ 0.6 |

### 3.2 三重防护
1. **身份锚定**：v_角色 通过 L2 持续注入 + 身份拦截句库（数据驱动的 OOC 负样本：EmoCompanion从不说"我是AI"）在解码期对"我是AI"等 token 序列做**硬抑制**（同 L1 机制，强度 2.5）。
2. **上下文管理**：超过 2k tokens → 滑窗压缩历史为「情感状态摘要 t + 最近 4 轮原文」；摘要保留 VAD 连续态（会话潮汐），不丢情感连续性。
3. **周期重锚**：每 8–12 轮向 system 注入一行"EmoCompanion基线"提醒（≤20 tokens，轻量），并在 OOC 检测超阈时**立即执行**重锚 + 恢复强度（对话情绪可漂移，人格常量不许漂移）。

## 四、数据产出优化（优化数据产出：打标 → 角色参数链路）

### 4.1 打标数据质量升级
- 置信度过滤：仅用 置信度 ≥ 0.9 的样本（当前 6951 合格 / 7030 总，先筛）。
- 口癖词袋去噪：低置信 transcript 不参与词袋计数（词袋会变脏——真人高频的"然后/作为"已在实测中被数据驱动剔除，证明该机制有效）。
- 双标仲裁：对 情感标签/情感演变 字段做一致性复核（已有质量评估报告基础上增量）。

### 4.2 新数据产品（每个都直接进角色包）
| 产品 | 来源 | 用途 | 预估量 |
|---|---|---|---|
| v_角色（高精度版） | **对比提示提取**（正："温柔撒娇喵主播小伴" / 负："理性正式主播"，各生成 20 条→中间层激活差）+ 层扫描选最优注入层 | L2 方向 | 1×d 向量 |
| 情绪转移示例库 | 按 情感演变/情感标签 抽"观众触发→EmoCompanion反应"短对话对（如 紧张→"哎呀~有点紧张呢…"） | 示例引导解码（L1 升级：压结构性元评论） | 50–100 对 |
| OOC 负样本库 | 扫描 6951 条里出现的身份泄漏句 + 人工补 | 身份拦截句库 | 30–50 条 |
| V/A/D 情感三维 | 打标已含 valence/arousal/dominance | 构建 v_角色 更丰富的方向空间 | 1×3 维 |

### 4.3 数据 → 角色包（≤10MB，热切换）
```
角色包.json = 人设提示段 + v_角色 + 示例库 + 身份拦截句库 + 正例词袋 + 空泛抑制表
切换 = 指针替换（无权重重载、无重打标）
```

## 五、算法优化清单（按优先级，均须过边际增益门）

| 项 | 内容 | 期望 | 依赖 |
|---|---|---|---|
| A. 示例引导解码 | 检索 1–2 条"情绪转移示例"拼入 prompt，压制"那我来给你解释一下"类元评论 | 去AI腔 +5 以上（补足上次 +3 的缺口） | 4.2 示例库 |
| B. P3 锚点精度 | 对比提示提取 v_角色 + 层扫描 | 综合保真 +1~3、人格一致性↑ | 4.2 v_角色 |
| C. P1.5 调度器标定 | 4B/7B/8B × β0.2–1.6 扫描，建"β-效果"曲线 | 消除 7B@β1.4 回退风险 | 调度器实装 |
| D. P4/P5 双通道 | 实装 L3 KV共振 + L4 DSA，P3×P4 配对 | 情绪起伏 82→88 | L2 先过门 |
| E. 去AI腔结构层 | 元评论句式抑制（续接抑制扩展到时序模式） | 去AI腔 +5~10 | 长对话语料 |

**已执行进展（2026-08）**：
- **B 已完成**：对比提示提取 v_角色（嵌入空间正负差）→ 情绪起伏 +2（81→83）、重复率 0.118 最低、综合 85 不退化，已优于 6 锚点加权法。层扫描：Qwen3-4B 判别力随层深单调上升，最优注入层 L35（36 层模型，**不可照搬文献 L20**——那属 26 层模型）。`p3_contrast.py` + `p3_contrast_eval.py`。
- **C 已完成**：4B 全 β 扫描（0.4–1.4）→ 保真 83–85 平坦、熵健康、无坍缩；β 敏感退化是 7B+ 特有（7B@1.4 回退 87→82）。调度器校准：熵<0.6 罕见=真坍缩信号（保留）；重复>0.15 在 4B 属基线共性（改**生成内回滚**而非全局降 β）。结论：4B 主推 β1.0、7B 封顶 β1.0。`p15_sweep.py`。
- L1 去AI腔 mild 已完成（71→74，`deai_opt.py`）。
- **D 已完成（诚实负结果）**：P4/P5 双通道实装并跑通（手动循环 + KV 缩放 + v_eff 合成，适配 transformers 5.14）。Qwen3-4B n=50：综合四条件全持平 84、情绪 80-81 无 +6 提升、P4@κ0.3 反而熵↓重复↑（不过边际增益门）→ **暂不启用 P4/P5**，降级为可选调参实验。`p45_dual.py`。
- **8GB 角色包当前最优堆叠**：人设提示段 + P3(β1.0) + L1 去AI腔(mild) + 对比 v_角色（优化二，情绪 +2 已确认）。
- **待办**：A（示例引导解码，补去AI腔结构性缺口）；P4/P5 需 κ∈{0.1,0.15} 小扫过门后才可复评；EmoScore 基线 + 30 轮 OOC 评测线（M0-M4）。

## 六、验收协议与里程碑

### 6.1 情感能力综合分 EmoScore（>70% 指标的可操作定义）
```
EmoScore = 0.5×情绪起伏(五维裁判0-100)
         + 0.3×min(100, 情感词密度/千字 × 25)      # cnsenti pos+neg
         + 0.2×min(100, 语义熵 × 100/0.60)          # 生成多样性
基线 = 裸模型(中性提示, 无 persona 无注入) 同 50 条测试集
验收 = EmoScore_全栈 ≥ 1.7 × EmoScore_基线  且  绝对分 ≥ 85
```
> 诚实说明：裸模型情绪起伏/情感密度/熵都偏低（估计 48–58），全栈目标 82–88 ⇒ 比值约 1.5–1.8×，**70% 处于可达成边界**，必须先跑基线实测校准，不预设成功。

### 6.2 里程碑
| 阶段 | 内容 | 出口验收 |
|---|---|---|
| M0 基线 | 裸模型 EmoScore + OOC 基线（30轮） | 拿到分母 |
| M1 骨架+指纹 | 人设提示 + L1 mild 去AI腔 + 身份拦截 | 保真 ≥86，去AI腔 ≥74，泄漏率 0 |
| M2 方向层 | 对比提示 v_角色 + P3（β 标定） | 过边际增益门，防复读确认 |
| M3 双通道 | L3+L4 实装 | 情绪起伏 ≥88，EmoScore ≥1.7×基线 |
| M4 长对话 | 30轮 OOC 验收 + 周期重锚 | 三 OOC 指标全过 |

### 6.3 三档显存复核（不退化约束）
每阶段跑 4B/7B/8B：稳态显存 4.5 / 8.3 / 10.6 GB 不劣化，注入额外开销 <1GB（情感计算全 CPU）。

## 七、预期与风险（诚实版）

- **预期**：EmoScore 相对裸模型 +70% 可达成（基线低+全栈多通道）；去AI腔在示例引导后可望 +5~10；30 轮 OOC 达标。
- **风险**：① 边际递减——保真已 86–92，>95 需更大模型；② EmoScore 基线若高于预期则 70% 收窄；③ P4/P5 显存增量需实测（预算 <1GB）；④ 多通道参数面变大 → 更依赖边际增益门严格把关。
- **不承诺**：不虚报"情感能力提升 70%"为绝对分数提升——它定义为**相对裸模型**的综合分提升，由 6.1 协议统一口径。
