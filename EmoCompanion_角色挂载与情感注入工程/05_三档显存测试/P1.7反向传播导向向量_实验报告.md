# P1.7 反向传播导向向量 —— 实验报告（截断点反向梯度 × 正向思考向量二次合并）

> 目标：验证用户 P1.7 假设——从**反向传播**角度重构 P1.5 的"思考链中断→算向量→中断插入"路线：
> ① 反向传播到中断点也截断，用角色条件损失对截断点隐状态求梯度得**反向向量**；
> ② 把反向向量与**原始思考段正向向量**做**二次合并**生成二次向量；
> ③ 以角色提示词（EmoCompanion人设）身份条件生成向量后做中断插入，是否更优？
> 复现：`p17_reverse.py [n]`（Qwen3-4B 4bit，n=10，seed=21）。
> 结论先行：**二次合并向量 E16 保真 88.0，为全场最优（+4.0 vs 基线，+2~3 vs 单路线）**；反向向量与正向向量**近乎正交**（cos=0.012），是一条真正的新控制轴；反向传播开销仅 ~1.1s/轮，完全可承受。

---

## 一、实验设计（9 条件，全部在角色提示词条件下）

| 条件 | 机制 | 对应思路 |
|---|---|---|
| A_base | 无注入 | 基线 |
| B_p3 | 正向锚点向量（P3 机制，静态） | 正向传播已验证路线（对照组） |
| C8 / C16 | 思考链截断 K=8/16 → **正向**思考向量（第18层隐状态均值） | P1.5 思路（"思考段向量数据不够"待验证） |
| D8 / D16 | 思考链截断 → **反向传播**向量：角色条件损失 L=CE(EmoCompanion风格续写\|prompt+思考段) 对截断点隐状态求梯度，取**负梯度**（梯度上升方向） | **P1.7 核心** |
| E16 | **二次合并**：0.6·反向 + 0.4·正向（均 L2 归一化后融合） | 用户核心假设 |
| E16_mid | E16 向量但**生成中段（step≥12）**才插入 | 中间插入测试 |
| D16_norole | **无角色提示词**（中性"助手"系统词）的反向向量 | 角色身份消融 |

注入机制与 P3 完全一致（公平对照）：`logits += β·tanh((emb_norm·v̂)/T)`，β=0.375（=0.5×4bit系数0.75），T=1.6，只读嵌入零权重。

## 二、环境

| 项 | 值 |
|---|---|
| GPU | RTX 3080 Laptop 16GB（实验期独占，起始空闲 458MiB） |
| 模型 | Qwen3-4B（bnb 4bit，device_map=cuda），裁判 Qwen3-8B（bnb 4bit） |

| 注入强度 | β=0.375，T=1.6，γ_bwd=0.6，mid_step=12，层=18/36 |

## 三、结果（n=10，seed=21）

| 条件 | 保真 | 语义熵 | 2-gram重复 | 速度 t/s | 情感词命中 |
|---|---|---|---|---|---|
| A_base | 84.0 | 0.804 | 0.105 | 7.1 | 61 |
| B_p3 | 85.0 | 0.790 | 0.094 | 7.7 | 51 |
| C8 | 86.0 | 0.814 | 0.110 | 7.6 | 56 |
| C16 | 85.0 | 0.796 | 0.099 | 7.4 | 62 |
| D8 | 85.0 | 0.834 | **0.092** | 7.3 | 49 |
| D16 | 86.0 | **0.855** | 0.109 | 7.3 | 57 |
| **E16（二次合并）** | **88.0** | 0.848 | 0.113 | 7.4 | 55 |
| E16_mid（中段插入） | 83.0 | 0.803 | 0.105 | 7.5 | 59 |
| D16_norole（无角色） | 83.9 | 0.810 | 0.098 | 7.3 | 56 |

### 3.1 向量几何（关键发现）

| 几何量 | 均值 | 解读 |
|---|---|---|
| cos(正向思考向量, 反向梯度向量) | **0.012** | **近乎正交**：反向向量不是正向向量的近似，是新控制轴 |
| cos(反向向量, P3目标方向) | −0.009 | 与锚点目标方向也正交 → 与 B_p3 机制互补不冗余 |
| cos(正向向量, P3目标方向) | 0.003 | 正向思考向量本身也不偏向锚点方向 |
| cos(有角色反向, 无角色反向) | 0.284 | 角色身份改变了约 92% 的向量能量方向（1−cos² 近似），**角色提示词是反向向量的主要信息来源** |

### 3.2 时间开销（每轮，Qwen3-4B 4bit）

| 环节 | 耗时 | 说明 |
|---|---|---|
| 思考链探针生成（16 token） | 2592.6 ms | C/D/E 共用，一次生成多路复用 |
| 正向思考向量（前向钩子） | 341.8 ms | |
| 反向传播向量（前向+反向图） | **1136.2 ms** | 反向比正向贵 ~3.3×，但绝对值可接受（探针总开销 4.1s/轮） |
| 解码期注入 | ~0 ms（logit 偏置） | 各条件速度 7.1–7.7 t/s 无差异 |

### 3.3 用户三个假设的裁决

1. **"P1.5 思考段正向向量数据不够"**：部分成立。C8（86.0）vs C16（85.0）差异在噪声内，说明 K=8 与 K=16 都"够用"，正向思考向量对数据量不敏感——它的问题不是数据不够，而是**信息天花板**（与反向向量正交，cos=0.012，说明两者编码了不同的角色信息）。
2. **"反向传播截断 + 二次合并是否更优"**：**成立**。E16 保真 88.0 全场最优，比单正向 C16（85.0）高 3.0，比单反向 D16（86.0）高 2.0，比基线高 4.0。正交的两条轴合并后互补生效。
3. **"以角色提示词身份生成反向向量是否必要"**：**成立**。D16_norole（83.9）比 D16（86.0）低 2.1 分且低于基线，无角色条件下反向向量甚至有负收益；几何上角色条件的反向向量能量方向 92% 不同。

### 3.4 中间插入测试

E16_mid（83.0）显著差于 E16（88.0，同为 E16 向量仅插入时机不同，差 **−5.0**）。**开场插入优于生成中段插入**：logit 偏置式注入在第一步就把采样分布导向角色风格，中段插入反而打断已形成的句内一致性。这与 P1.5 报告"注入零开销、机制不可坍缩"的结论一致，但排除了"延迟插入更稳"的猜测。

## 四、与 GitHub/文献调研的对照（查新）

- **"截断点反向梯度向量 + 正向思考隐状态二次合并"未见直接先例**（GrAInS arXiv:2507.18043 用 Integrated Gradients 选 token/层但不做截断二次合并；GeoSteer arXiv:2601.10229 在生成中途做潜空间梯度更新但不基于思考截断；K-Steering arXiv:2505.24535 每步前向+反向开销大得多）。P1.7 的"探针式离线反传 → 解码期零开销注入"组合在查新意义上站得住，可作为专利/论文的差异点。
- 反向向量近乎正交于正向向量这一点与 GrAInS 的结论呼应（梯度归因方向 ≠ 激活均值方向），本项目首次在**中文角色情感注入**场景量化了这一正交性（cos=0.012）。
- llama.cpp 侧落地路径已明确：repeng / llama.cpp `--control-vector` 原生支持"HF 离线算向量 → GGUF 推理插"，P1.7 反向向量可走同一管线（合规于本项目"GGUF 单一部署"硬约束）。

## 五、局限与下一步

1. **n=10 偏小**：±2~3 分波动在噪声边缘（P1.5 在 n=30 时波动≈±1）。E16 的 +4.0 优势方向明确但需 **n=30 复验**（复跑 `python p17_reverse.py 30`，约 1 小时）。
2. 反向向量目前只取第 18 层单层、单条角色续写损失；可扩展为多层加权 + 多条续写平均（GrAInS 式 top-k 归因）进一步提纯。
3. γ_bwd=0.6 为单点；建议扫 γ∈{0.4,0.6,0.8} 找二次合并最优配比。
4. GGUF 迁移：将 E16 蒸馏为 llama.cpp control vector（repeng export_gguf），在 llama-tts/EmoCompanion线上链路验证，彻底摆脱推理期 transformers 依赖。

## 六、结论

P1.7 假设**整体成立**：反向传播向量与正向思考向量近乎正交、携带角色身份信息、单独使用与正向等效（且熵更健康 0.855、重复更低 0.092），**二次合并（0.6 反向 + 0.4 正向）取得全场最优保真 88.0**；反向传播增量开销仅 1.1s/轮、峰值显存 6.15GB，在 16GB 消费级卡上完全实时可行。插入时机结论：**开场插入，不做中段插入**。
