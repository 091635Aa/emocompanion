# Qwen3-RapSynth 技术报告（框架版）

> 项目代号：Qwen3-RapSynth —— 基于 Qwen3-TTS 与外挂韵律路由的说唱合成框架。
> 阶段：科研框架构建。笔记本电源约束下**不触发模型训练**；交付可运行的端到端管道 + 真实合成样例 + 客观基线。

## 1. 方法

### 1.1 总体路线
`歌词 + BPM + 风格` → **韵律预测器**（`ProsodyPlan`：逐行 F0/时长/能量/句拍）→ **Qwen3-TTS 逐行中性合成**（Base + 音色 LoRA + `target_speaker_embedding.pt`）→ **间接韵律注入**（对拍 `time_stretch` + `pitch_shift` + 能量增益 + 拍网格编排）→ **干声 wav + 逐行 onset + 客观评估**。

### 1.2 关键结论（Phase 0 控制面探查）
- **任务书前提「Qwen3-TTS 原生支持 pitch_curve/duration/能量」经验证不成立**（读透官方开源源码 + 真实合成探针）。
- 公开 Base 仅有 `ref/voice_clone_prompt` 音色条件 + 采样参数；本地仅有 Base + Tokenizer，无 VoiceDesign/CustomVoice 变体。
- **采用间接控制面**：音色走 x-vector（`ref_spk_embedding`，`(1,2048)` 已验证）；节奏/音高/能量走采样级后处理 + 拍网格编排。详《01_控制面探查报告.md》。

### 1.3 韵律预测器
- 阶段交付**规则先验基线**（快嘴平直 / 旋律拱形 / 硬核下探），零训练、可解释，供给人类可审计的对照；学习预测器遵守同一 `ProsodyPredictorBase` 接口待数据就绪接入。详《03_韵律预测器.md》。

## 2. 实验与结果

### 2.1 合成样例（`output/samples/`，24kHz 干声）
| 文件 | 风格 | BPM | 时长 |
|---|---|---|---|
| `快嘴_96bpm.wav` | 快嘴 | 96 | 15.97s |
| `旋律说唱_84bpm.wav` | 旋律说唱 | 84 | 30.36s |
| `硬核_72bpm.wav` | 硬核 | 72 | 20.83s |

### 2.2 客观指标（基线数字，《04_评估.md》全表）
对拍误差 0.10–0.18s，BPM 漂移 0.85–0.91，F0 RMSE 90–111Hz，押韵命中与能量对比待行内细化。

### 2.3 已知瓶颈 → 下一步增益方向
1. **行级 pitch_shift 无法还原音素级 F0 曲线** → 学习预测器输出**音素级 F0 序列**后按帧注入。
2. **句休止非整数拍**导致 BPM 漂移高 → 行/休止对齐到整数小节。
3. **能量等增益未下沉行内** → 音节级重音交替。
4. **数据不足**：无合规说唱数据集 + 未装 MFA → `prepare_prosody_data.py` 已就绪，待数据。

### 2.4 消融/基线对比（已实测，`docs/04` 全表）
以同一批中性干声派生「无注入基线 / 行级注入 / 音节级脉动」并实测 onset 对拍误差：
- `音节级脉动` **0.1468s** < `无注入基线` **0.1637s**（优化 ~10%）→ **粒度越细越有效**，印证「音素级 vs 音节级」验证必要；
- `行级注入`与基线持平、F0 RMSE 略升（变速/变调引入基频偏差）→ 行级间接后处理不足以构成韵律增益；
- **结论**：真正的说唱韵律增益须靠 **Phase 2 学习韵律预测器在音素级逐帧注入**；该缺失被实测证明而非假设。

## 3. 工程结构
```
07_说唱合成Qwen3RapSynth/
├── prosody_model/rules.py     韵律预测器（规则基线 + 统一接口）
├── integration/injector.py    间接韵律注入（对拍编排）
├── tts/synthesizer.py         Qwen3-TTS 基座（x-vector/ICL 两条路径）
├── eval/metrics.py            客观指标
├── scripts/
│   ├── probe_control.py       Phase0 控制面探查
│   ├── generate_rap.py        一键生成 CLI（歌词+风格+BPM → 干声）
│   └── prepare_prosody_data.py 韵律数据准备
├── docs/00~04                  本体系报告
└── output/samples/            三风格干声样例
```

## 4. 运行
```bash
python scripts/generate_rap.py --style 快嘴 --bpm 96            # 全链路合成
python scripts/generate_rap.py --no-tts --style 旋律说唱 --bpm 84  # 框架校验（无 GPU）
python scripts/probe_control.py --out probe_result.json         # 控制面探查
python scripts/prepare_prosody_data.py --src <wav+txt> --out <split>
```

## 5. 风险与合规
- 数据集一律开源/合规，标注来源与许可（科研伦理）。
- 间接后处理的音质损耗通过 rate 0.7–1.5、半音阈值约束。
- 方法不伪造 Qwen3-TTS 不存在的声学注入，结论可复现、接口可升级。
