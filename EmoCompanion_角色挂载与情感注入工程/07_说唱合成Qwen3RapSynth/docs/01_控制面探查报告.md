## 2. 实测控制面（到底能控制什么）

### 2.1 公开 API 签名（`Qwen3TTSModel`）
| 方法 | 暴露的参数 |
|---|---|
| `generate_voice_clone` | `text, language, ref_audio, ref_text, x_vector_only_mode, voice_clone_prompt, non_streaming_mode` + 采样（`do_sample/top_k/top_p/temperature/repetition_penalty/max_new_tokens`） |
| `generate_custom_voice` | `text, speaker, language, instruct, non_streaming_mode` + 采样 |
| `generate_voice_design` | `text, instruct, language, non_streaming_mode` + 采样 |
| `create_voice_clone_prompt` | `ref_audio → ref_code + ref_spk_embedding + icl_mode` |

- **无**`pitch_curve`、`duration_curve`、`energy`、`speak_rate`、`prosody` 等任何声学参数。
- 底层 `Qwen3TTSForConditionalGeneration.generate()`（源码全文检索）同样**无**上述关键字；唯一“外形”相近的是 `duration` 因子被用于**外部位移重采样/画头**与 `tat` 无关的 mask 计算，并非可控注入。

### 2.2 本地实际可用的模型变体
- 仅下载了 `Qwen3-TTS-12Hz-1.7B-Base` + `Qwen3-TTS-Tokenizer-12Hz`。
- **没有** VoiceDesign / CustomVoice 变体 → `instruct` 文本风格控制、`speaker` 预置音色这两条路径本地不可用（Base 的 `generate` 也拒绝非 base 模型类型）。

### 2.3 真实合成探针
- 骨架在原版之上做了修正，并以训练期导出的 `target_speaker_embedding.pt`（`(1,2048)`）作为 `ref_spk_embedding` 走 `x_vector_only_mode=True` 路径：**成功合成**「EmoCompanion」音色反馈干声，验证了「无需 ref_audio 的稳定音色路径」（源码 `speaker_embed.view(1,1,-1)` 与 2048 维匹配）。

## 3. 结论与取舍
| 假设 | 结论 |
|---|---|
| pitch_curve 显式注入 | ❌ 不支持 |
| duration 显式注入 | ❌ 不支持 |
| 能量显式注入 | ❌ 不支持 |
| `instruct` 文本风格控制 | ⚠️ 仅 VoiceDesign/CustomVoice 变体，本地无 → 降级不可用 |

**采用的控制面（间接，Phase 3 实现）**：
1. **音色** — `voice_clone_prompt.ref_spk_embedding`（x-vector，稳定角色音色，已验证）。
2. **节奏/时值** — 逐句/逐行中性合成后，用 `librosa.effects.time_stretch` 按 ProsodyPlan 的目标时长缩放到拍长（快嘴压缩、旋律舒展）。
3. **音高** — `librosa.effects.pitch_shift` 按行级 `mean_f0` 相对基准音高的半音差升降（旋律拱形、硬核下探）。
4. **重音/能量** — 按行 `energy` 系数线性增益（限幅），叠加在拍网格上。
5. **句拍/切分** — 语句按行分割、句间静音休止，逐行拼接到 `start_sec` 拍网格（快嘴/硬核留半拍、旋律留一拍）。

> 意义：这是「**原生生成 + 韵律后处理对拍**」的诚实验证——不伪造 Qwen3-TTS 不存在的声学注入；把 Phase 2 韵律预测器输出的 F0/时长/能量，落到可解释的采样级控制上。其真实增益体现在「对拍对齐误差、BPM 漂移、F0 RMSE、重音对比」等客观指标上（见 `docs/04_评估.md`）。

## 4. 后续风险
- 间接后处理（time-stretch/pitch-shift）有音质损耗上限：rate 限制 0.7–1.5，半音偏移幅度设阈值，避免明显失真。
- `instruct` 文本风格控制可作为**未来购置 VoiceDesign 变体后的增强路径**，与现有后处理正交。
