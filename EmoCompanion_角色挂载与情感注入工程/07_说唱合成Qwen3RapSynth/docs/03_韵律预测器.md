# Qwen3-RapSynth · 03 韵律预测器

> 说明：本规格为科研框架阶段，遵守「框架默认不训练」。当前交付的是**规则先验基线**（已实装并随端到端管道跑通）与一套**学习模型统一接口**。学习模型的按需小规模训练在数据就绪后据此接口一键接入。

## 1. 统一协议（`ProsodyPredictorBase`）
所有预测器（规则基线 or 学习模型）实现同一个接口，保证 Phase 4 注入层可无缝替换：

```python
class ProsodyPredictorBase:
    def predict(self, lyrics: str, bpm: float, style: str,
                base_f0: float = 180.0) -> ProsodyPlan: ...
    def is_learned(self) -> bool: ...
```

`ProsodyPlan` 由多行 `LinePlan` 组成，每行携带 **syllables / start_sec / duration_sec / mean_f0 / f0_style / energy / jump** —— 即控制器要消费的全部韵律参数。

## 2. 规则先验基线（已实装 · `prosody_model/rules.py`）
可解释、零训练，作为学习模型的对照（证明「数据驱动增益」的下限）：

| 风格 | F0 轮廓 | 时长策略 | 能量 | 句间休止 |
|---|---|---|---|---|
| 快嘴 | 平直（flat，近朗读） | 半拍/字，压缩 | 1.15 | 半拍 |
| 旋律说唱 | 拱形（arch，随句相位升降 ±18%） | 一拍/字 | 0.95 | 一拍 |
| 硬核 | 下探（punch） | 半拍/字 | 1.35 | 一拍 |

## 3. 学习模型设计（已实装微型版，遵守同一协议）
- **目标**：`text+BPM/句拍 → 每音素 F0 / 时长 / 能量系数`，直接产出可被注入层消费的 `LinePlan` 平局等效对象。
- **选型论证（三选一，倾向可控+轻量）**：
  - Transformer 自回归：长程依赖好，但需大量数据且训练重；
  - LSTM 序列：轻量、对短行节奏学习稳定，**优先**；
  - 扩散模型：韵律为连续分布，表达强，但采样慢、工程复杂，作为进阶。
- **约束**：16GB 显卡 `batch_size=1 + grad_accum`，尺度小收敛快；仅在校验后按需触发，不阻塞框架。
- **数据**：由 `scripts/prepare_prosody_data.py` 产出 CSV/JSONL（F0/时长/能量）；MFA 对齐（若装）提升音素级精度，否则字符级占位对齐。

### 3.1 已实装：LSTM 学习预测器（烟测/管道冒烟）
`prosody_model/learned.py` 提供可用的小型 LSTM（字符嵌入 → 双向 LSTM → 条件(style/bpm) → 逐音节回归头，输出 F0 半音偏移/时长缩放/能量）。因当前无合规说唱数据 + 未装 MFA，用**规则先验 teacher 生成逐音节伪标签**做教师蒸馏，跑通「训练→推理→注入」全链路：

```
python scripts/train_prosody_predictor.py --epochs 8 --device cpu
# 产物 prosody_model/weights/prosody_lstm.pt；自动选型 rules.get_predictor() → is_learned=True
```

实测（本机 CPU 数秒级）：loss 10.0 → 2.06，generate_rap 计划 `f0_style="learned"`。**定位（诚实）**：这是管道冒烟、证明可替换规则基线；真实增益须在拿到 MFA 对齐的真实 F0/时长标签后重训（只需替换 `build_label_dataset()` 数据来源）。

### 3.2 逐音节 F0 轮廓注入（已实装并自检通过）
`integration/injector.apply_f0_contour` 接收学习预测器逐音节输出的半音偏移，把每行按音节数分窗、逐窗做 time-varying pitch（段缘淡变防爆音），在**行内**还原 F0 起伏，替代原先行级单次 `pitch_shift`。机制自检 `scripts/test_f0_contour.py`（CPU/确定性）：恒定 180Hz 谐波 + 目标 deltas `[0,3,-3,1]`，实测四窗 F0 `180.8/213.8/152.1/190.5` ≈ 目标 `180/214.1/151.4/190.7`，跨度 61.7Hz——证明「音素≈音节级」F0 轮廓注入有效，是学习预测器逐音节输出可直接消费的控制接口。
