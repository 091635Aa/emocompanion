## 1. POST /chat —— 对话

请求体（JSON）：
```json
{
  "messages": [{"role": "user", "content": "晚上好呀，今天直播好多人来，我好开心，你呢？"}],
  "max_new": 128,
  "temperature": 0.9,
  "top_p": 0.9,
  "top_k": 50,
  "use_layers": true,
  "role": "default",
  "seed": null
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| messages | array | 是 | 多轮消息 `[{role, content}]`，role ∈ user/assistant |
| max_new | int | 否 | 最大生成 token（默认 128） |
| temperature | float | 否 | 采样温度（默认 0.9） |
| use_layers | bool | 否 | 是否启用三层注入（P3锚点+去AI腔+OOC，默认 true） |
| role | string | 否 | 扩展包（角色）名，默认 "default" |
| seed | int | 否 | 固定随机种子 |

响应：
```json
{
  "role": "default",
  "reply": "哎呀~家人们都来啦？...",
  "usage": {"prompt_tokens": 233, "completion_tokens": 64, "total_tokens": 297},
  "latency_s": 4.126,
  "tok_s": 15.51
}
```

## 2. GET /roles —— 查看角色（扩展包）

响应：
```json
{"active": "default", "roles": ["default"]}
```

## 3. POST /roles/{name} —— 切换角色

- 路径参数 name = 扩展包名（如 `default`）
- 角色包位于 `04_源码与原型/data/role_pack/role_pack_{name}.json`
- 新角色包放入该目录后重启服务自动发现

## 6. CLI 交互工具（clidoc 附录）

`04_源码与原型/backend/cli.py` 支持命令行请求：

```bash
# 扫描模型与扩展包
python cli.py list
python cli.py scan

# 对话（多种请求格式）
python cli.py chat "你好呀"                        # 引号文本
python cli.py chat 晚上好呀 今天开心吗              # 空格分隔
python cli.py chat '{"messages":[{"role":"user","content":"hi"}],"max_new":64}'  # JSON
python cli.py chat -i                               # 交互多轮模式

# 定向启动（指定模型 + 扩展包）
python cli.py chat -m Qwen3-4B-Q4_K_M -p default "你好呀"
python cli.py serve --port 8000 -m Qwen3-4B-Q4_K_M -p default
```

## 8. 三层情感注入说明

服务端 `use_layers=true` 时启用：
- **L2 P3 锚点注入**：`logits += β·tanh(S·v_target/T)`，预计算 bias（151936 维）
- **L1 去AI腔**：正例词袋 boost + 空泛词抑制
- **OOC 拦截**：身份泄漏短语硬抑制（"我是AI"等）

设 `use_layers=false` 获得裸模型输出（对照/调试用）。
