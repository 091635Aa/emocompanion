# 第二十章 实战练习手册：12 个动手任务

光看不练等于白学。这一章给你 **12 个由浅入深的动手任务**，从"跑起第一个模型"到"做一个带长期记忆的 AI 陪伴机器人"。每个任务都给出目标、步骤和验收标准，做完这套练习，你就真正"会" RWKV 了。

## 任务 1：跑起你的第一个 RWKV

- **目标**：本地成功运行 RWKV 并对话；
- **步骤**：

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama run mollysama/rwkv-7-g1:2.9b
```

- **验收**：能正常和它聊几句，比如问"你是谁？""1+1=？"。

## 任务 2：验证"状态记忆"的存在

- **目标**：亲眼看到多轮对话有记忆；
- **步骤**：告诉它"我叫小明，我喜欢蓝色"，聊几句后再问"我叫什么？我喜欢什么颜色？"；
- **验收**：它能答出"小明、蓝色"（而不是完全失忆）。

## 任务 3：对比速度稳定性

- **目标**：验证"聊得再久也不慢"；
- **步骤**：连续聊 10 轮以上，每轮记录回复耗时；
- **验收**：第 1 轮和第 10 轮耗时接近，没有明显变慢。

## 任务 4：体验上下文长度

- **目标**：体验长上下文优势；
- **步骤**：喂给它一篇长文章（几千字），让它总结；
- **验收**：能正常读完并总结，不报内存错误。

## 任务 5：调整采样参数，感受"温度"

- **目标**：理解 temperature 的作用；
- **步骤**：分别用 temperature=0.2 和 1.0 让它写一首诗，对比风格；
- **验收**：低温更稳、高温更有想象力，能描述出区别。

## 任务 6：用 Modelfile 造一个角色

- **目标**：给模型设定人设；
- **步骤**：写一个"温柔心理咨询师小暖"的 Modelfile，`ollama create` 后运行；
- **验收**：它的语气明显变成了你设定的风格。

## 任务 7：通过 API 调用

- **目标**：用代码调用模型；
- **步骤**：用 curl 或 Python（openai 库）调用 `/api/chat`；
- **验收**：能拿到 JSON 回复，并能解析出文本内容。

## 任务 8：实现流式输出

- **目标**：体验打字机效果；
- **步骤**：Python 里用 `stream=True` 逐块打印；
- **验收**：文字逐段冒出，而不是一次性全部返回。

## 任务 9：保存和恢复状态

- **目标**：实现跨会话记忆；
- **步骤**：用 `rwkv` 库对话，把 state 存成 .pkl，重启进程后恢复再聊；
- **验收**：重启后模型还记得之前聊的内容。

## 任务 10：做一个情感感知的陪伴机器人

- **目标**：把情绪检测 + 人设 + 状态记忆组合起来；
- **步骤**：按第十二章的思路，实现 `detect_emotion` + 按情绪调整回复 + 状态持久化；
- **验收**：用户说"我好难过"，机器人能先共情再回应，且记得用户名字。

## 任务 11：搭建一个迷你 RAG

- **目标**：让模型"查资料"回答；
- **步骤**：用 Chroma + embedding 建一个小知识库，实现"提问 → 检索 → 注入 → 生成"；
- **验收**：模型能根据你提供的资料回答，而不是瞎编。

## 任务 12：做个完整的选型决策

- **目标**：能把 RWKV 放进真实项目里；
- **步骤**：选一个你真实的业务场景，用第十三章的决策表判断"该不该用 RWKV"，并给出部署方案（Ollama / llama.cpp / vLLM 三选一）；
- **验收**：写出一页纸的方案：场景痛点 → 为什么选 RWKV → 部署架构 → 风险与对策。

## 进阶挑战（可选）

- **挑战 A**：用 RWKV-Runner 加载 .pth 模型，比较 Albatross 与默认后端的性能；
- **挑战 B**：把 RWKV 接到微信/网页机器人，实现"随时在线陪伴"；
- **挑战 C**：用 RWKV-PEFT 对一个角色做 State Tuning，对比挂载前后的人设稳定性；
- **挑战 D**：在树莓派或旧笔记本上部署 1.5B 量化模型，测真实速度。
