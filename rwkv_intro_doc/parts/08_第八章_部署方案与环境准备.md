# 第八章 怎么用起来：部署方案总览与环境准备

从这一章开始进入"实战"。我们会先给你一张"部署选型地图"，再手把手教你装好环境，为后面的命令行、API、Python 调用铺路。**目标是：让一个完全没部署过模型的小白，也能把 RWKV 跑起来。**

## 8.1 先搞清楚：你要用哪种方式？

RWKV 目前有非常多种跑法，适合不同的人。先看这张流程图，选一个适合自己的入口：

![部署选型流程图](img/fig15_deploy_flow.png)

| 入口 | 适合谁 | 难度 | 特点 |
| --- | --- | --- | --- |
| **Ollama** | 新手、想最快跑起来 | ★☆☆ | 一条命令下载+运行，自动提供 OpenAI 兼容 API |
| **RWKV-Runner** | 想要图形界面、可调参数 | ★☆☆ | 桌面 GUI，一键加载 .pth，支持挂载 State |
| **llama.cpp（GGUF）** | 低配设备、CPU 用户 | ★★☆ | 量化模型，内存极省，命令行/服务两种模式 |
| **HuggingFace + Python** | 开发者、要自定义逻辑 | ★★★ | 直接用 transformers / rwkv 库加载，最灵活 |
| **vLLM / SGLang** | 生产环境、高并发服务 | ★★★ | OpenAI 兼容服务，吞吐高 |
| **RWKV Pip / Albatross** | 研究、想用官方内核 | ★★★ | 官方 .pth 直接推理，支持 State 读写 |

**新手建议**：先从 **Ollama** 或 **RWKV-Runner** 入手，1 分钟跑起来有感觉了，再去看 Python 或服务化方案。

## 8.2 模型大小怎么选

RWKV 全系开源，规模从 0.1B 到 7.2B 都有。选多大取决于你的硬件：

| 模型规模 | 参数量 | 量化为 Q8 后大小 | 适合硬件 |
| --- | --- | --- | --- |
| RWKV-7 1.5B | 15 亿 | 约 1.6GB | 4GB 内存/显存即可 |
| RWKV-7 2.9B | 29 亿 | 约 3GB | 8GB 内存/显存 |
| RWKV-6 7B | 70 亿 | 约 7GB | 12GB+ 内存/显存 |
| RWKV-6 14B | 140 亿 | 约 14GB | 24GB+ 显存（多语最强） |

> **选型口诀**：先选一个"跑得动的最小模型"验证流程，再逐步升级。CPU 用户优先考虑 1.5B / 2.9B 的 GGUF 量化版；有 NVIDIA GPU 再上更大规模。

## 8.3 方式一：Ollama（最推荐给新手）

### 8.3.1 安装 Ollama

- **Windows / macOS**：去 [ollama.com](https://ollama.com) 下载安装包，双击安装即可；
- **Linux**：

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

安装完成后，在终端输入 `ollama --version` 能输出版本号即成功。

### 8.3.2 拉取并运行 RWKV 模型

RWKV 社区成员 @MollySophia 维护了官方的 RWKV-7 模型库。直接运行：

```bash
# 运行 RWKV-7 G1 2.9B（推荐，默认带思考模式）
ollama run mollysama/rwkv-7-g1:2.9b
```

Ollama 会自动下载模型并进入对话界面，像和 ChatGPT 聊天一样直接打字。常见参数：

| 模型 tag | 说明 |
| --- | --- |
| `mollysama/rwkv-7-g1:2.9b` | 2.9B，Q8_0 量化，默认带思考模式 |
| `mollysama/rwkv-7-g1:1.5b` | 1.5B，更轻量 |
| `mollysama/rwkv-7-g1:2.9b-thinkdisabled` | 关闭思考模式（更快） |
| `mollysama/rwkv-7-world:2.9b` | 老版 World 模型（不推荐，G1 更全面） |

> 提示：默认思考模式下，可以用 `/set nothink` 和 `/set think` 在终端里随时切换思考模式开关。

### 8.3.3 Ollama 的 OpenAI 兼容 API

Ollama 默认在 `http://localhost:11434` 提供 API，几乎和 OpenAI 接口一致，方便程序调用：

```bash
curl http://localhost:11434/api/chat -d '{
  "model": "mollysama/rwkv-7-g1:2.9b",
  "messages": [{"role": "user", "content": "用一句话介绍 RWKV"}],
  "stream": false
}'
```

## 8.4 方式二：RWKV-Runner（图形界面）

如果你更习惯"点鼠标"，用 **RWKV-Runner**（rwkv.cn 提供）体验最好：

1. 去 rwkv.cn 下载 RWKV-Runner 安装包（支持 Win/macOS/Linux）；
2. 打开软件，选择模型文件（.pth 或 .gguf 都支持）；
3. 选择"后端/Strategy"：
   - 默认用 **RWKV Pip**（`cuda fp16` 或 `cpu fp32`）；
   - NVIDIA 显卡 + RWKV-7 可切换 **Albatross**（`albatross workers=1 batch=32`）做性能对比；
   - GGUF 量化模型用 **llama.cpp** 后端；
   - 苹果/AMD 等 WebGPU 设备用 **WebGPU** 后端；
4. 点击启动，即可在自带聊天界面使用，还能挂载 State、调整 Temperature 等参数。

> **后端小知识**：后端（Backend）决定"哪套程序加载并运行模型"；Strategy 是"加载配置"（设备、精度、上下文长度）；量化是"权重的保存精度"。三者不要混淆。

## 8.5 方式三：llama.cpp + GGUF（低配设备最爱）

llama.cpp 是 CPU 也能高效跑模型的老牌工具，RWKV 的 GGUF 量化模型对它支持良好。

### 8.5.1 获取 GGUF 模型

RWKV 的 GGUF 模型可以从 Hugging Face 集合（如 `zhiyuan8/models`）下载，推荐用 `FP16` 或 `Q8_0` 量化档（更低的 Q5/Q4 会明显降低回复质量）。

### 8.5.2 命令行运行

```bash
# llama-cli 交互式对话
./llama-cli -m path/to/model.Q8_0.gguf -p "你好"

# 或启动一个 OpenAI 兼容的服务（llama-server）
./llama-server -m path/to/model.Q8_0.gguf --port 8080 --ctx-size 8192
```

启动服务后，可用 `http://localhost:8080/v1/chat/completions` 调用，和 OpenAI 格式一致。

## 8.6 方式四：HuggingFace + Python（开发者的首选）

要用代码做自定义逻辑（对话机器人、RAG、State 保存等），直接在 Python 里加载最灵活。

### 8.6.1 安装依赖

```bash
pip install rwkv rwkv_tokenizer
# 或（用 transformers 生态时）
pip install transformers huggingface_hub
```

### 8.6.2 从 HuggingFace 下载模型

```bash
huggingface-cli download BlinkDL/rwkv7-g1 \
  rwkv7-g1b-1.5b-20251202-ctx8192.pth \
  --local-dir /path/to/models
```

或用 Python：

```python
from huggingface_hub import hf_hub_download
model_path = hf_hub_download(
    repo_id="BlinkDL/rwkv7-g1",
    filename="rwkv7-g1b-1.5b-20251202-ctx8192.pth",
    local_dir="/path/to/models",
)
```

> 国内网络慢的话，可以设置镜像：`export HF_ENDPOINT=https://hf-mirror.com`。

## 8.7 方式五：vLLM（生产环境高并发）

要在生产环境提供服务、支撑高并发，用 vLLM（官方支持 RWKV）：

```bash
pip install vllm

python -m vllm.entrypoints.openai.api_server \
  --model BlinkDL/rwkv7-g1 \
  --host 0.0.0.0 --port 8000 \
  --max-model-len 8192 \
  --gpu-memory-utilization 0.85
```

启动后即获得 OpenAI 兼容的 `/v1/chat/completions` 接口，吞吐量高、适合多用户场景。

## 8.8 通用环境检查清单

无论你选哪条路，先确认环境是好的：

```bash
# 1. Python 版本（建议 3.10+）
python3 --version

# 2. 显卡（有 NVIDIA GPU 才需要）
nvidia-smi

# 3. pip 本身
pip install --upgrade pip setuptools wheel

# 4. 磁盘空间（模型通常 2~15GB）
df -h
```

| 硬件情况 | 推荐方案 | 预期体验 |
| --- | --- | --- |
| 无 GPU，仅 CPU | llama.cpp GGUF / Ollama CPU | 1.5B 约 5-10 tok/s，够聊天 |
| 8GB 内存的迷你主机 | Ollama 2.9B 量化 | 稳定 4-5 tok/s，长对话不崩 |
| NVIDIA 8GB 显存 | RWKV Pip / Albatross fp16i8 | 2.9B 流畅，可上 7B 量化 |
| NVIDIA 24GB+ 显存 | vLLM / Albatross | 7B/14B 高吞吐服务 |

<div class="tip">

**本章小结**：跑 RWKV 有五种主流方式——Ollama（最易）、RWKV-Runner（图形界面）、llama.cpp（CPU/低配）、HuggingFace+Python（灵活）、vLLM（生产）。新手从 Ollama 起步，开发者用 Python，生产用 vLLM。模型先选跑得动的最小档，验证流程后再升级。
