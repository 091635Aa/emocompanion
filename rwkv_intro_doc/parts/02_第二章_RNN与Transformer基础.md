# 第二章 基础铺垫：先认识 RNN 和 Transformer

要理解 RWKV 为什么特殊，得先知道它站在谁的肩膀上。这一章我们用最通俗的方式，把两个"前辈"——**RNN** 和 **Transformer**——讲清楚。它们正是 RWKV 想要"取其精华、去其糟粕"的对象。

## 2.1 什么是"序列"和"语言模型"

在进入架构之前，先明确两个概念：

**序列（Sequence）**：一串有先后顺序的数据。比如一句话"我喜欢吃苹果"，就是 5 个词组成的序列；一段心电图、一首歌的波形、一行股票价格，也都是序列。大语言模型要处理的，就是这种"有前后顺序"的文本。

**语言模型（Language Model）**：本质是一个"猜下一个词"的游戏。给它看"我喜欢吃____"，它预测下一个最可能是"苹果"还是"火锅"。GPT 能写文章、聊天，底层都是这一个动作：**根据已看到的词，预测下一个词**，然后不断重复。

所以任何语言模型都要解决一个核心问题：**如何利用"前面看过的内容"来预测"下一个词"**。RNN 和 Transformer 给出了两种完全不同的答案，RWKV 给出了第三种。

## 2.2 RNN：一边走一边记（循环神经网络）

RNN（Recurrent Neural Network，循环神经网络）是最早的答案之一，诞生于 1980-1990 年代，LSTM（长短期记忆网络）是它的著名改良版。

RNN 的思路非常朴素：**我一边读文本，一边把"印象"记在一个小本子上（隐藏状态），读下一个词时，既看这个词，也翻一翻小本子。**

![RNN 循环结构](img/fig01_rnn_loop.png)

上图就是 RNN 的核心：一个"网络 A"每吃进一个输入，就更新自己的记忆，并输出一个结果；而这个记忆又会被"传回给自己"，参与下一次计算。把它按时间展开，就是下面这张更直观的图：

![RNN 按时间展开](img/fig02_rnn_unfold.png)

注意看：x0→x1→x2… 是连续输入的词，A 是同一个网络（同一套参数）被反复使用。**这正是 RNN 的招牌优点：参数少、天然有记忆、内存占用固定**——因为不管序列多长，它只需要保留一份"隐藏状态"。

**但 RNN 有三个著名缺点：**

1. **健忘（梯度消失）**：记性会随距离衰减，早期看的内容越传越淡，学不会"长距离依赖"。比如让它读一篇万字小说，它常常忘了开头。
2. **不能并行（串行计算）**：必须一个词一个词按顺序算，第 5 个词必须等第 4 个词算完。训练大模型时，GPU 无法同时发力，慢得离谱。
3. **训练不稳**：深层 RNN 容易出现梯度爆炸等问题。

所以 RNN 虽然"省"，但"笨且慢"，在大模型时代被 Transformer 取代了。

## 2.3 隐藏状态：理解 RWKV 的钥匙

"隐藏状态（hidden state / state）"这个词非常重要，因为 **RWKV 的整套设计都是围绕它展开的**。请务必理解：

> **隐藏状态 = 模型对"到目前为止看到的一切"的压缩摘要，相当于模型的"心理状态 / 记忆"。**

想象你在追一部剧：你不需要记住每一帧画面，大脑里留下的是一份"剧情摘要"——主角是谁、发生了哪些关键事件、现在进展到哪。这份摘要会随着剧情不断更新。隐藏状态就是这个"剧情摘要"。

RNN 每读一个词，就更新一次隐藏状态；RWKV 也完全一样。**理解"隐藏状态"就理解了 RWKV 的一半**，因为 RWKV 的核心创新，就是设计了一套"特别会做摘要、摘要又能并行生成"的隐藏状态更新规则。

## 2.4 Transformer：注意力机制的颠覆者

2017 年，Google 发表《Attention Is All You Need》，提出 Transformer，彻底改变了 NLP 领域。它的核心是**自注意力（Self-Attention）**。

自注意力的直觉是：**每个词在理解自己时，都要"看看"序列里所有其他词，并判断谁跟它关系大。** 比如在"银行"这个词出现时，模型要判断上下文里的"存钱"还是"河岸"，来理解这里是"银行"还是"河岸"。

实现上，每个词会生成三个向量：

- **Query（查询）**：我到底在找什么信息？
- **Key（键）**：我是谁，我携带什么"检索标签"？
- **Value（值）**：我携带的具体内容是什么？

![Transformer 单层结构](img/fig03_transformer_block.png)

然后每个 Query 会跟所有词的 Key 算相似度（打分），分数经过 softmax 变成"注意力权重"，再用这些权重去加权求和所有 Value。谁跟当前词关系大，谁的 Value 就贡献得多。

![自注意力与 N×N 矩阵](img/fig04_attention.png)

**这样做的最大好处是：**

1. **记忆精确**：每个词都能直接"翻旧账"，看任意远的词，没有"健忘"问题。
2. **完全可并行**：所有词之间的配对关系可以同时计算，GPU 全力开火，训练飞快。

正因如此，Transformer 成了 ChatGPT、Llama 等几乎所有现代大模型的基础，横扫 NLP。

## 2.5 Transformer 的痛：O(N²) 和 KV Cache

Transformer 再强，也有一个绕不开的代价——**复杂度随序列长度 N 呈平方级增长（O(N²)）**。

- **计算上**：N 个词两两配对，需要算 N×N 个分数。序列长度翻倍，计算量变 4 倍；翻 4 倍，计算量变 16 倍。
- **内存上（KV Cache）**：推理时，为了不再重复计算历史，模型会把每个历史词的 Key 和 Value 都缓存起来（叫 **KV Cache**），随对话/文本变长，缓存线性增长，最终吃掉所有显存。

这就是为什么"长文本"和"多轮长对话"对 Transformer 是噩梦：**要么贵得离谱，要么内存爆掉。**

## 2.6 两大架构优缺点一表流

| 特性 | RNN（LSTM 等） | Transformer |
| --- | --- | --- |
| 记忆机制 | 隐藏状态（固定大小） | 自注意力 + KV Cache |
| 训练并行 | 不能并行，串行慢 | 完全并行，训练快 |
| 推理内存 | 固定（O(1)） | 随上下文增长（KV Cache） |
| 长距离记忆 | 差（健忘/梯度消失） | 强（任意距离直接关联） |
| 计算复杂度 | O(N) 线性 | O(N²) 平方 |
| 记忆精确度 | 低（压缩摘要） | 高（完整保留原文） |

现在你应该看出来了：**RNN 省但不强，Transformer 强但不省。** 那能不能造一个"又强又省"的架构？这正是 RWKV 诞生的动机——它的所有设计，都是在回答这个问题。
