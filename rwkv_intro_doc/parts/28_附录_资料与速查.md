## A.2 快速上手：三步跑通 RWKV

```bash
# 第 1 步：安装 Ollama（Linux 为例）
curl -fsSL https://ollama.com/install.sh | sh

# 第 2 步：拉取并运行 RWKV-7
ollama run mollysama/rwkv-7-g1:2.9b

# 第 3 步（可选）：用 API 调用
curl http://localhost:11434/api/chat -d '{"model":"mollysama/rwkv-7-g1:2.9b","messages":[{"role":"user","content":"你好"}],"stream":false}'
```

## A.3 命令速查表

### A.3.1 Ollama

| 命令 | 作用 |
| --- | --- |
| `ollama run <model>` | 运行模型并进入对话 |
| `ollama pull <model>` | 下载模型 |
| `ollama list` | 查看已下载模型 |
| `ollama create my-model -f Modelfile` | 用 Modelfile 创建自定义模型 |
| `ollama serve` | 启动 API 服务（默认 11434） |
| `ollama rm <model>` | 删除模型 |

### A.3.2 llama.cpp

| 命令 | 作用 |
| --- | --- |
| `./llama-cli -m model.gguf -p "你好"` | 命令行交互 |
| `./llama-server -m model.gguf --port 8080` | 启动 OpenAI 兼容服务 |
| `./llama-bench -m model.gguf` | 性能测试 |

### A.3.3 vLLM

| 命令 | 作用 |
| --- | --- |
| `pip install vllm` | 安装 |
| `python -m vllm.entrypoints.openai.api_server --model ... --port 8000` | 启动服务 |

### A.3.4 HuggingFace / Python

| 命令 | 作用 |
| --- | --- |
| `huggingface-cli download <repo> <file> --local-dir <dir>` | 下载模型 |
| `export HF_ENDPOINT=https://hf-mirror.com` | 切换国内镜像 |
| `pip install rwkv rwkv_tokenizer` | 安装官方推理库 |

## A.4 常用环境变量

```bash
# HuggingFace 镜像（国内加速）
export HF_ENDPOINT=https://hf-mirror.com

# 关闭 HuggingFace 的联网检查（离线环境）
export HF_HUB_OFFLINE=1

# 指定模型缓存目录
export HF_HOME=/path/to/hf_cache
```
