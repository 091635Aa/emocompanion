# 第十八章 高效架构家族：RWKV vs Mamba vs RetNet

RWKV 并不孤单。在"用状态代替注意力"这条路上，还有 Mamba、RetNet、Gated DeltaNet 等一批高效架构。这一章帮你建立全局观：它们各自怎么"省"、差异在哪、RWKV 的位置和优势是什么。

## 18.1 为什么大家都在"去注意力"

Transformer 的 O(N²) 是行业痛点，于是出现了一整条研究路线：**用"固定大小的状态/记忆"替代"两两配对的注意力"**，把复杂度降到 O(N) 甚至 O(1)。这些架构统称"线性注意力 / 状态空间 / 高效序列模型"。

## 18.2 逐个认识家族成员

### 18.2.1 Mamba（SSM 派）

- **思想**：来自控制论的**状态空间模型（SSM）**，把序列建模看成"连续系统 + 离散采样"；
- **关键机制**：选择性扫描（selective scan）——每个位置决定"吸收多少新信息"；
- **特点**：训练可用并行扫描，推理是常数开销；在某些长序列任务上表现出色。

### 18.2.2 RetNet（微软）

- **思想**：显式引入**衰减（decay）**，用"线性注意力 + 衰减"模拟位置效应；
- **特点**：提出三种并行模式，推理也可常数开销；和 RWKV 思路较接近（都有显式衰减）。

### 18.2.3 Gated DeltaNet

- **思想**：把 **Delta 规则**引入状态更新——让状态能"修正"而不是只能"累积"；
- **特点**：和 RWKV-7 的 DSE 思想一脉相承（都强调"可更新的记忆"）。

### 18.2.4 RWKV

- **思想**：R / W / K / V 四件套——**感受态门控 + 显式可学衰减 + 键值写入 + 值读出**；
- **特点**：100% 无注意力、训练并行 + 推理常数、有 State Tuning 独家能力、从 0.1B 到 7.2B **全系开源可商用**。

## 18.3 一张表对比全家

| 架构 | 记忆机制 | 复杂度 | 训练并行 | 推理成本 | 代表模型 |
| --- | --- | --- | --- | --- | --- |
| Transformer | 自注意力 + KV Cache | O(N²) | 完全并行 | 随上下文增长 | GPT/Llama/Qwen |
| Mamba | SSM 状态 + 选择机制 | O(N) | 并行扫描 | 常数 | Mamba-1/2 |
| RetNet | 线性注意力 + 显式衰减 | O(N) | 并行 | 常数 | RetNet |
| Gated DeltaNet | Delta 规则状态 | O(N) | 并行 | 常数 | 研究/小规模 |
| RWKV | R/W/K/V 状态 | O(N) | 并行 | 常数 | RWKV-4~7 |

## 18.4 RWKV 的差异化优势

和同族相比，RWKV 有几个"别人没有"的特点：

| 特点 | 说明 |
| --- | --- |
| **100% 无注意力** | 架构里完全没有 self-attention（有些混合模型仍保留稀疏注意力） |
| **全系开源可商用** | 0.1B–7.2B 模型、代码、内核均 Apache 2.0，Linux 基金会项目 |
| **State Tuning** | 可微调隐藏状态，个性化/对齐又快又省，是 RNN 系独有能力 |
| **状态可持久化** | 状态 S 可直接序列化保存/恢复，天然支持跨会话记忆 |
| **多语言强** | RWKV-7 在 3B 多语言任务上刷新 SOTA |
| **生态可直接用** | Ollama/llama.cpp/vLLM/RWKV-Runner 均已支持，开箱即用 |

## 18.5 和其他架构的常见误区澄清

### 误区一："RWKV 就是 Mamba"

**不是。** 虽然都属于"线性注意力/状态"家族，但机制不同：Mamba 来自 SSM（连续系统离散化），RWKV 来自 RNN + 显式衰减 + Token Shift。RWKV 强调"R/W/K/V 四件套 + 可学衰减"，Mamba 强调"选择性扫描"。

### 误区二："高效架构效果都不如 Transformer"

**分任务。** 在标准 benchmark 上，头部高效架构（含 RWKV-7）已能与同规模 Transformer 打平甚至超过；在"状态追踪"等特定推理任务上，RWKV-7 理论上还能超过注意力受限的模型。真正有差距的是"超大模型规模下的极致效果"和"生态成熟度"。

### 误区三："线性注意力都有严重记忆损失"

**旧版确实有，但已改善。** RWKV-7 的动态状态演化让状态可修正，大幅缓解了记忆"只进不出"的问题；不过对"逐字精确回忆"仍弱于完整注意力，因此出现了 RWKV-X 等"状态 + 稀疏注意力"的混合方案。

## 18.6 混合架构趋势：RWKV-X

最近的一个方向是**混合架构**：以状态记忆为主干，在关键位置混入少量稀疏注意力，兼顾"便宜"和"精确回忆"：

- **RWKV-X**：RWKV + 稀疏注意力，补强极端细节回忆；
- **RWKV-8 DeepEmbedAttention**：精简 KV Cache，特别适合混合模型；
- **类似趋势**：很多大厂也在做"线性 + 稀疏"混合，这可能是未来主流形态。

> **判断**：纯 RNN 派（RWKV）、SSM 派（Mamba）、混合派（RWKV-X / 各类 linear-attention hybrid）会长期共存，各取所长。

## 18.7 我们该选谁？（选型参考）

| 你的情况 | 建议 |
| --- | --- |
| 要现成可用、全系开源、中文好、能商用 | **RWKV**（生态成熟、开箱即用） |
| 只研究架构、喜欢 SSM 理论 | Mamba |
| 追求极致长序列（超长文档） | Mamba / 混合架构（扫描式更适合极长序列） |
| 要做 AI 陪伴/长会话 + 个性化 | **RWKV**（State Tuning + 状态持久化是独门优势） |
| 要最新效果、算力充足 | 头部 Transformer |
