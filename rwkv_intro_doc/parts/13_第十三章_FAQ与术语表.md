# 第十三章 常见问题、选型决策与术语表

最后一章：把大家最常见的疑问集中解答，给出"到底选不选 RWKV"的决策框架，并附上一份可直接查阅的术语表。到这里，你就从"小白"升级成"能独立判断和动手"的 RWKV 使用/选型者了。

## 13.1 常见问题 FAQ

### Q1：RWKV 是 RNN 还是 Transformer？

**RNN 变体。** RWKV 推理时以循环方式工作（每步只带一份状态），但训练时又能像 Transformer 一样并行。它是"RNN 的身板 + Transformer 的训练效率"，但不含任何自注意力。

### Q2：RWKV 会取代 Transformer 吗？

**不会立刻取代，而是多一种选择。** 在长对话、低资源、边缘、私有化场景，RWKV 性价比更高；在极致效果、成熟生态、极致长上下文精确回忆场景，Transformer 仍是主流。两者互补。

### Q3：RWKV 的"无限上下文"是真的吗？

**推理成本上接近无限**（内存/速度不随长度暴涨），但**记忆质量有上限**——毕竟是压缩摘要，极长时会有信息损失。工程上建议"长上下文 + 分段总结/检索"配合。

### Q4：RWKV 和 Mamba 有什么区别？

都属于"状态空间/线性注意力"家族，但实现不同：Mamba 用连续系统离散化 + 输入相关选择机制；RWKV 用显式可学习衰减（W）+ 感受态门控（R）+ Token Shift，且是 100% 无注意力、全系开源可跑。RWKV 的独特卖点还包括 State Tuning。

### Q5：我的电脑能跑吗？

- 8GB 内存：跑 1.5B / 2.9B 量化没问题；
- 8GB 显存：可跑 2.9B fp16 或 7B 量化；
- 只有 CPU：跑 1.5B 量化能聊天（约 5-10 tok/s）。

### Q6：RWKV 商用要钱吗？

**免费。** RWKV 模型、代码、内核均为 Apache 2.0 开源，属于 Linux 基金会项目，可自由使用、修改、商用。

### Q7：为什么要开启官方 CUDA 内核？

RWKV-6/7 的数据相关衰减让并行计算变复杂，官方 WKV 内核能大幅提速。用 RWKV Pip / Albatross / vLLM 等方案会自动利用，建议保持开启。

### Q8：RWKV 的多语言效果怎么样？

**很好，且是强项。** RWKV-7 在 3B 规模多语言 benchmark 上刷新 SOTA，非英语语言尤其突出；RWKV-6 World 14B 覆盖大量语言。

### Q9：我想让 RWKV 变成某个角色，最省的方法是什么？

**State Tuning。** 不动权重、只调状态，几乎零成本换"性格"，效果甚至比提示词更稳定，还能迁移复用。

### Q10：RWKV 现在有哪些模型可以选？

| 模型 | 规模 | 特点 |
| --- | --- | --- |
| RWKV-7 G1 | 1.5B / 2.9B | 最新，带思考模式，推荐 |
| RWKV-7 World | 1.5B / 2.9B | 老版 World 系列 |
| RWKV-6 World | 7B / 14B | 多语言，14B 最强 |
| RWKV-6 / v4 系列 | 0.1B–7B | 社区广泛使用 |

## 13.2 选型决策框架：我到底该不该用 RWKV？

用一个"打钩表"帮你快速决策：

| 判断问题 | 是 → 倾向 |
| --- | --- |
| 场景是长对话/多轮陪伴？ | RWKV |
| 硬件资源有限（低显存/CPU/边缘）？ | RWKV |
| 需要私有化/离线/合规？ | RWKV |
| 要低成本做个性化人设？ | RWKV |
| 需要极致长上下文的精确回忆？ | Transformer |
| 需要最先进效果、算力充足？ | Transformer |
| 需要丰富生态/成熟工具链？ | Transformer |
| 生产高并发服务？ | 两者都可（RWKV 也能 vLLM） |

**决策口诀**：省、快、私、长会话 → RWKV；准、全、顶、成熟生态 → Transformer。绝大多数"AI 陪伴/情感智能体"属于前者。

| K / V | Key / Value | 写入记忆的键与值 |

## 13.4 全书一句话回顾

如果你只记住一点，请记住这句：

> **RWKV 是一种"没有自注意力、用固定大小状态记忆一切"的大模型架构——它用"笔记式记忆"换来了 Transformer 的并行训练和 RNN 的恒定成本，在长对话、低资源、个性化、私有化场景里，是把"够聪明 + 够便宜"同时做到的最优解之一。**

从第一章到现在，我们已经走完了：**它是什么（第1-3章）→ 它特殊在哪（第4-5章）→ 和 Transformer 差在哪（第6章）→ 为什么能行（第7章）→ 怎么用（第8-10章）→ 怎么定制（第11章）→ 怎么落地到我们的项目（第12章）**。剩下的，就是动手了。
