# 第十七章 公式通俗课：RWKV 的数学只讲直觉

很多教程一上来就甩公式，小白直接劝退。这一章反着来：**只讲公式背后的直觉**，把 RWKV 的核心数学用"买菜、记账、做笔记"的比喻讲清楚。你不需要会推导，只需要"看懂它想干什么"。

## 17.1 预备：向量、矩阵、点积，用生活语言理解

- **向量**：一列数字，可以理解成"一个东西在多维空间的坐标"。比如"苹果"可以用 [甜度, 价格, 热量, ...] 表示；
- **矩阵**：一堆向量排成表格；
- **点积（内积）**：两个向量对应位置相乘再求和。**直觉：衡量两个向量有多"相似/对齐"**。方向一致 → 点积大；方向垂直 → 点积为 0。

> 记住"点积 = 相似度打分"，RWKV 的数学就通了一半。

## 17.2 四个字母的数学直觉（R / W / K / V）

| 字母 | 数学角色 | 生活直觉 | 通俗公式 |
| --- | --- | --- | --- |
| R | 感受态（门控系数） | "这条信息我接受多少" | R 乘在最终结果上 |
| W | 衰减系数 | "记忆忘得多快" | 越旧乘越小的系数 |
| K | 键 | "这条信息叫什么名字" | 用于"对号入座" |
| V | 值 | "这条信息的实际内容" | 真正被记住的内容 |

## 17.3 WKV 算子：三句话讲清核心公式

RWKV-4 的经典 WKV 公式（不背，只看结构）：

```text
output_t = R_t · (  Σ_{i<t}  exp(-w·(t-i)) · (K_i · V_i)  +  exp(u)·(K_t · V_t) )
```

拆成三句话：

1. **`K_i · V_i`（写入）**：每个历史词把"名字 × 内容"记进状态——就像记账时写下"日期 × 金额"；
2. **`exp(-w·(t-i))`（衰减）**：越早的账目乘的衰减系数越小——就像老账目被时间冲淡；
3. **`R_t`（读出/门控）**：当前这个词决定"这段记忆对我重不重要"——就像翻账本时只挑有关的看。

> **一句话**：WKV = 把历史"按新旧打折后求和"，再乘一个"要不要管它"的开关。

## 17.4 为什么是"指数衰减"而不是"直接忘掉"

- **指数衰减**：`exp(-w·(t-i))` 让旧信息**平滑地、按比例地**变淡，但不会瞬间归零——远亲也能沾点光；
- 对比 RNN 的"梯度消失"（失控地忘）：RWKV 的衰减是**显式、可学习**的（W 是训练出来的参数），所以模型能自己决定"该记多久"。

> 这正是 RWKV "不健忘"的秘密：把"遗忘"从玄学变成可调的旋钮。

## 17.5 Token Shift 的数学

```text
Shift(x[t]) = μ · x[t] + (1 - μ) · x[t-1]
```

- 就是"当前值"和"上一个值"按比例混合；
- μ 是混合比例（不同通道可以不同）；
- 效果：每个 token "自带一点上一时刻的影子"，补充邻近信息。

**为什么叫"短卷积"**：它等价于一个核长 2 的卷积，几乎零成本，却能显著提升表现——RWKV 的"以小博大"典型例子。

## 17.6 Channel Mixing 的数学

```text
out = sigmoid(R) ⊙ ( W2 · gelu(W1 · K) ) ⊙ V
```

逐块拆解：

| 符号 | 含义 | 直觉 |
| --- | --- | --- |
| `W1 · K` | 线性变换 | 把输入换个"视角"看 |
| `gelu(...)` | 非线性激活 | 引入非线性，增强表达 |
| `W2 · ...` | 再变换 | 加工后回到原维度 |
| `sigmoid(R)` | 门控 | 决定"这些特征要不要激活" |
| `⊙` | 逐元素相乘 | 逐位把关 |

> **一句话**：Channel Mixing 就是在"同一个时刻"上，把特征加工得更丰富，再按需放行——作用类似 Transformer 的 FFN。

## 17.7 RWKV-7：动态状态演化（广义 Delta 规则）

RWKV-7 的状态更新比 v4 复杂，但直觉更简单——**会改错**：

```text
旧版（v4）： S = 衰减 · S + K·V        # 只能写，不能改
新版（v7）： S = S · 门控 + 基于误差的修正   # 能写，还能改
```

用"做笔记"比喻：

- **v4**：一边读一边记，但记错了就一直错下去；
- **v7**：读完一段会"对答案"，发现记错了就**修正笔记**——所以记性更好、更会"状态追踪"。

这正是论文里说的"**元上下文学习器**"：模型在每个 token 上，用"上下文里的梯度下降"自我调整状态。

## 17.8 复杂度的数学：为什么差一个 N

- Transformer：N 个词两两打分 → 需要 N×N 次 → **O(N²)**；
- RWKV：每个词只更新一次固定状态 → 需要 N 次 → **O(N)**。

```text
O(N²)  vs  O(N)
N=4K：1600万  vs  4000
N=32K：10亿    vs  3.2万
```

这就是"长上下文不心疼"的全部秘密——**少算了一个 N 的配对**。

## 17.9 一张"公式 → 直觉"对照表

| 公式/术语 | 数学形式 | 生活直觉 |
| --- | --- | --- |
| 点积 K·V | Σ K_i·V_i | 记下"名字×内容" |
| 指数衰减 | exp(-w·(t-i)) | 老账按比例冲淡 |
| 感受态 R | sigmoid(R) | 开关：要不要管它 |
| Token Shift | μ·x[t]+(1-μ)·x[t-1] | 瞥一眼上一句 |
| 归一化分母 | /Σ exp(-w·(t-i)) | 让账本总和不发散 |
| Delta 规则（v7） | S←S·D+误差修正 | 记错了就改 |
| 前缀和并行 | cumsum | 摊开来一次算完 |
