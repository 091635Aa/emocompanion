# 第二十三章 社区生态：谁在做、去哪学、怎么参与

RWKV 不是一个人在战斗。这一章带你认识它背后的"江湖"——社区在哪、有哪些核心项目、模型生态长什么样，以及如果你想参与贡献，该从哪里下手。

## 23.1 一个开源项目的生命力来自社区

判断一个开源模型值不值得长期投入，除了看架构本身，还要看**生态是否活跃**。RWKV 在这点上相当有底气：它是**中国第一个达到 GPT 级性能的开源语言模型**，也是 Linux 基金会（AI & Data 基金会）旗下的首个生成式 AI 托管项目，背后有全球范围的开发者协作。

| 社区阵地 | 说明 | 适合谁 |
| --- | --- | --- |
| GitHub（RWKV-LM） | 源码、模型、v1–v8 各版本、训练代码 | 开发者、研究者 |
| Discord（RWKV 官方） | 全球开发者实时讨论、内核优化、新版本内测 | 深度用户、贡献者 |
| rwkv.cn 中文社区 | 中文教程、RWKV-Runner、部署指南、问答 | 中文用户、小白 |
| Hugging Face | 各版本模型权重、GGUF 量化、微调产物 | 使用者、部署者 |
| 官方 Wiki | 架构史、部署教程、论文解读 | 想深入原理的人 |

**一句话建议**：刚上手就去 rwkv.cn 找教程 + RWKV-Runner 一键跑通；想深入就在 GitHub 和 Discord 泡着；想找现成模型/量化文件就去 Hugging Face。

## 23.2 核心项目地图：这些"零件"都该认识

RWKV 生态不是只有一个仓库，而是一整套工具链。认识它们，你就知道遇到问题时该找谁：

![RWKV 生态核心项目](img/fig25_ecosystem.png)

| 项目 | 定位 | 一句话作用 |
| --- | --- | --- |
| **RWKV-LM** | 主仓库 | 模型定义、训练/推理代码、官方权重发布 |
| **RWKV-Runner** | 图形界面 | 一键下载/运行/聊天/微调，Windows/Mac 小白神器 |
| **RWKV-PEFT** | 微调工具 | LoRA 微调、State Tuning（状态微调） |
| **Albatross** | 推理内核 | RWKV-7 的 CUDA / ROCm 高性能内核，显著提速 |
| **rwkv（pip）** | 官方推理库 | Python 里加载/推理 RWKV 的推荐方式 |
| **rwkv_tokenizer** | 分词库 | RWKV 专用 tokenizer（世界模型分词） |
| **RWKV pip / vLLM** | 服务框架 | 高并发 OpenAI 兼容 API 服务 |
| **Ollama / llama.cpp** | 通用推理 | 通过 GGUF 格式跑 RWKV，最省心 |

> **怎么选**：个人体验 → RWKV-Runner 或 Ollama；Python 集成 → `pip install rwkv`；生产高并发 → vLLM / Albatross；要改模型 → RWKV-LM + RWKV-PEFT。

## 23.3 模型生态：你现在能拿到什么

RWKV 生态的模型非常"全"：从 **0.1B 到 14B** 全系开源，且都带 Apache 2.0 商用许可。按发布时间和使用热度，大致可以分成几代：

| 系列 | 代表模型 | 特点 | 适合场景 |
| --- | --- | --- | --- |
| RWKV-4 | 1.5B / 3B / 7B | 经典版，稳定，社区资料多 | 学习、轻量部署 |
| RWKV-5 / 6 | World 0.1B–14B | 多语言强化，14B 最强 | 中文/多语言、生产 |
| RWKV-7 G1 | 1.5B / 2.9B | 最新，带思考模式，DSE 状态机制 | 推荐首选、长对话 |
| RWKV-7 World | 1.5B / 2.9B | 多语言版 | 多语言需求 |
| RWKV-X | 实验混合架构 | 结合线性注意力的最新尝试 | 尝鲜、研究 |

**获取模型的三种途径：**

```bash
# 方式一：Ollama 直接拉（最省心）
ollama run mollysama/rwkv-7-g1:2.9b

# 方式二：Hugging Face（含 GGUF 量化）
huggingface-cli download BlinkDL/rwkv-7-g1-2.9B-0.1B-preview \
  rwkv-7-g1-2.9B-0.1B-preview-GGUF-Q4_K_M.gguf --local-dir ./rwkv

# 方式三：RWKV-Runner 图形界面内一键下载
```

## 23.4 怎么从社区"借力"：提问与检索的姿势

好的问题 = 一半的答案。社区里高效求助的姿势是这样的：

1. **先搜再问**：先搜 GitHub Issues、rwkv.cn 问答、Wiki，八成问题已被解决。
2. **说清环境**：`模型版本 + 框架（Ollama/llama.cpp/pip）+ 硬件（显存/内存）+ 报错全文`。
3. **提供复现**：最小可复现的代码或命令，比一大段描述有用得多。
4. **报错给日志**：把完整报错堆栈贴出来，别只贴"它报错了"。
5. **英文问题去 Discord，中文问题去 rwkv.cn**：在哪问就用那的语言。

<div class="warn">

**避坑提醒**：不要在社区问"RWKV 能不能打 GPT-5"这类没有标准答案的对比题；要把问题改成"在 XX 场景、XX 资源约束下，RWKV-7 和 Qwen 谁更合适"这种可决策的问题，才能得到有效回答。

## 23.5 如何从"使用者"升级为"贡献者"

参与开源不只是"写代码"。RWKV 社区几乎每个人都能找到适合自己的贡献方式：

| 贡献方式 | 难度 | 你能得到什么 |
| --- | --- | --- |
| 反馈 bug、提 Feature 建议 | ★ | 社区信誉、问题被修 |
| 写/翻译中文教程、Wiki | ★ | 帮助新人、个人品牌 |
| 提供量化模型（GGUF/INT8） | ★★ | 部署者感谢、下载量 |
| 测试新版（RWKV-7/8 内测） | ★★ | 第一时间体验、反馈价值 |
| 为 vLLM / llama.cpp 修 bug | ★★★ | 开发者认可、合入主仓库 |
| 训练/微调开源模型 | ★★★ | 影响力、研究产出 |
| 优化内核（Albatross） | ★★★★ | 极高认可度（需要 CUDA 功底） |

**入门路线**：先在本地跑通一个模型 → 写一篇使用笔记发到 rwkv.cn → 尝试给 Wiki 补一节教程 → 提交一个文档 PR。从小事做起，慢慢就会找到自己感兴趣的方向。

想跟上 RWKV 的最新进展，盯住这几类信号即可：
