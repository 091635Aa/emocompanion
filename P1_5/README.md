# 语义回响（Semantic Echo）· 统一工作区（P1 → P1.5 → P2.5 → P3 → P4 → P5）

> **一句话介绍**：语义回响家族 **P1→P5 推理期（decoding-time）情感增强架构**的统一工作区——不依赖微调基座，
> 方案覆盖**表示 / 配置 / 概率 / 嵌入 / 注意力缓存**五个操作空间，P5 实现**一体化全合成（P1×P2×P3×P4 机制级融合）**。
> 代表成果含 LLM-Judge 混合 +91%（P2.5）、HeartBench +21.7% 与 TuringBench 人似度 +200%（P3）、
> P3×P4 双通道 win_rate 全场最高（P4，+23%）、P5 超融合验证「四架构同链路底层融合」机制可行。

> **编号说明（最终版，2026-08-10）**：P1 语义回响 → P1.5 通用兼容层（基于 P1 的自动适配层）→ **P2.5 情感潮汐解码（潮汐 ETD）**→

## 三、方案一句话定位（最终编号）

| 编号 | 名称 | 操作空间 | 一句话机制 | 代表成果 | 需本地权重 | 闭源 API |
|---|---|---|---|---|---|---|
| P1 | 语义回响 | 表示空间 | hidden_state 钩子→回响池质心→`logits+=质心@投影×λ` | 熵 +17.9%~+45%（E1–E13 全套验证） | 必须（钩子） | 否 |
| P1.5 | 通用兼容层 V2 | 配置空间 | 扫描表+公式+架构族/量化因子自动适配 λ/γ/τ + 思考链中断兜底 | 任意模型自动适配，未注册兜底命中 0.2166 ≥ 已注册 0.1572 | 必须 | 否 |
| P2.5 | 情感潮汐解码 ETD | 概率空间 | 外部 VAD 感知 → 采样乘性重加权 `p′∝p^(1-α)·q^α`（数学上不可能坍缩）+ AI 腔抑制 | LLM-Judge 潮汐回响混合 **+91%**（v4.2）、v8+人设 0.5167 | 可选 | 可 |
| P3 | 锚点回响 AE | 嵌入空间 | 模型自身 embedding 权重**只读**接口 → 6 维锚点稠密余弦打分 → tanh 极性注入（三级接口降级） | HeartBench **+21.7%**、TuringBench **+200%**、LLM-Judge+人设 **+56.25%**、打分表仅 3.6MB | 可选 | 可（三级降级） |
| P4 | KV 情感共振 KER | 注意力缓存空间 | 稠密打分表在 KV 缓存定位情感 token → `K[p] *= 1+κ·clip(g,0,1)` 注意力共振（softmax 天然有界） | P3×P4 双通道 win_rate **0.2667（+23%）全场最高** | 可选（本地缓存） | 需降级 |
| P5 | 超融合解码器 UFD（合成方案） | 全空间机制级融合 | DSA（P1×P4 动态方向）+ DMR（P3×P4 稠密乘性）+ P1.5 参数贯穿 = 一体化全合成 | 四架构同链路底层融合可行；DMR 0.1667~0.1833 | 可选 | 需降级 |

## 四、使用说明

1. **怎么开始**：读 `00_总览\总总结_P1到P4.md` 与 `结果对比总表.md` → 打开 `总结报告\` 下 PDF 总览 → 按需进入各方案 `实验报告\实验报告总览_分批.md` → 再到 `源码\` 复现。
2. **P4/P5 复现**：`c:\Users\Administrator\Documents\KV 情感共振解码\核心\`，`python P5验证测试.py`（KV 五模式）→ `python 超融合对比测试.py`（UFD 五模式）；依赖 torch 2.6+ / transformers 5.x / cnsenti / jieba，RTX 3080 16GB（fp16）。
3. **模型依赖**：主战模型 Qwen2.5-1.5B-Instruct（本地路径见各报告），裁判 Qwen2.5-7B-Instruct（8bit/bf16）；P3 云裁判 deepseek-v4-flash / pro（`thinking` 开关不影响判定方向）。
4. **P2.5（潮汐）源码路径注意 ⚠️**：多数脚本通过 `sys.path` 注入 `回响工程根 = i:\Desktop\语义回响`（import semantic_echo 包），且日志/结果默认输出至 `h:\情感潮汐解码（Emotion Tidal Decoding, ETD）`；迁移后运行前需按需修改脚本中的路径变量。

## 五、注意事项

- 数字一律来自 `00_总览\` 两份文档与各方案分批报告 + KV 评测（`P5_实验报告.md`、`超融合对比_结果.json`），未编造；拿不准处以 `~` 标注。
- 最终编号：P1=语义回响、P1.5=通用兼容层、P2.5=ETD（潮汐）、P3=AE、P4=KER、P5=UFD（合成方案）；文档/文件名中出现的「P5」「原P3/原P4」均指旧编号（KV=旧 P5）。
- **潮汐回响 = P1 × P2.5**（回响×潮汐混合，即 P2.5 报告内的混合注入器 v4.2，LLM-Judge +91%），是 P2.5 的核心成果而非独立方案。
- LLM-Judge 跨代口径：P2.5 潮汐/混合基于 30 集样本（60 配对）；P3 +人设基于 60 条优化样本抽 30 条；P4/P5 基于 30 条 × 每模式**不同种子**（裸100/锚点200/超融合300/KER400/双通道500），绝对胜率对种子高度敏感。
- 共通结论：1.5B 基模表达力是最终瓶颈——解码期引导只能缩小差距，无法突破基座天花板；AI 腔抑制是 LLM-Judge 最大破绽（P2.5 结论，P4/P5 单通道不敌裸同因）。
