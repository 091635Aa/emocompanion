# P3 情感潮汐解码 实验报告总览（分批）

> 本总览按里程碑（M0–M6）组织，汇总 P3 情感潮汐解码（Emotion Tidal Decoding, ETD）的全部实证批次。数据来自 `架构说明\第三套方案_情感潮汐解码ETD.md`（含全部 M 系列数字）、`实验报告\对照结果\`、`实验报告\评测结果\`、`实验报告\图灵测试\` 下迁移的原始 JSON，未做任何编造；拿不准或口径受限的数字以 `~` 标注并注明来源。

## 方案一句话

**情感潮汐解码（ETD）**：与前两代（表示空间 hidden_state 回响注入 / 配置空间调参）正交的第三套方案——在**概率空间**做外部认知引导。感知层把对话文本投影为连续 VAD 情感状态（潮汐轨迹），决策层算出共情目标分布与自适应引导强度 α(t)，表达层在采样时做乘性重加权 `p'(w) ∝ p(w)^(1-α)·q_emo(w)^α`（数学上不可能坍缩）。批实验从 M1 三层构建 → M4 同种子对照 → M5 系列评测接入/定向优化 → 图灵测试，最终把 LLM-Judge 盲评胜率从裸 0.1833 推到混合 v4.2 的 0.35（+91%）、v8+人设 N5 的 0.5167（+48%）。

## 批次详解

### 里程碑 M1–M3 感知/决策/表达层构建

- **目的**：从 0 构建三层独立模块（不修改任何现有源码，与架构一/二正交，闭源 API 亦可用）。
- **实现自检**：M1 中英文 VAD 方向性核对通过（"开心"→V 正、"崩溃"→V 负高唤醒）；M2 α、密度目标随输入情感强度单调递增、冷场不引导；M3 情感 token 表构建成功（单 token 情感词、无常用字污染），乘性重加权用对数域等价实现。
- **核心创新**：`p'(w) ∝ p(w)^(1-α)·q_emo(w)^α` 是有界插值（α∈[0,1]），数学上不可能坍缩——与 P1 的 logits 加法（可碾压原分布）形成本质差异。
- **结论**：三层就绪，进入对照验证。

### M4 同种子对照（裸 vs 潮汐）

- **目的**：同种子、同模型（Qwen2.5-1.5B，种子 42，5 组提示）验证"外部认知引导单独有效"。
- **数据**（`对照结果\对照_20260809_035102.json`，与 ETD 文档一致）：语义熵 1.3563→1.4092（**+0.053**）、重复率 0（无坍缩）、情感命中率 0.1784→0.1835（**+0.005**）；失恋/担心妈妈场景共情表达明显增强；中性场景 α=0 输出完全一致。
- **早期版本对照**（同目录 `对照_20260809_034426/034808/051031.json`）：v1 无极性版本命中率反而微降（-0.0069~-0.0146）、熵提升有限，印证后续 v2.1 极性定向的必要性。
- **结论**：潮汐单模式有效且无坍缩，进入评测接入。

### M5 / M5b–M5d 评测接入与 v2.1

- **M5 HEART-BENCH 共情基准**（`评测结果\HEART_BENCH_潮汐.json`，10 题，7B 裁判）：共情 0.75→0.72（持平）、一致性 0.60→0.75（**+0.15**）、有效决策率 100%（无坍缩）。结论：MCQ 自由度低，潮汐优势在自由对话更显著；一致性提升证明情感引导使决策更稳定。
- **M5b EmoCharacter 角色基准**（10 角色×4 轮，单 run）：匹配 fidelity 0.795→0.813（+0.018）、中性下限 0.605→0.605（地板未动）、无坍缩。结论：增强角色情感表达且不污染中性回复。
- **M5c HeartBench 人味儿基准**（20 题）：overall 31.79→28.82（-2.97）、情绪维度 33.99→29.39（-4.60）。结论（适用边界）：HeartBench rubric 看重主动性/简洁口语化，情感词密度增强反而不利 → 潮汐定位明确为**情感表达/共情任务专用**，非通用"人味儿"增强。
- **M5d 潮汐 v2.1（极性定向 + 角色主导 + 跨轮会话）**：修复 3 缺陷（情感 token 表无极性→错配虚高；引导幅度 α/T×|V|≈0.07 太弱→k=α×倍率；EmoCharacter 每轮新建感知器轨迹不累积→跨轮复用 + 角色 VAD 基调主导）。EmoCharacter：匹配 0.795→0.815、一致性识别率 0.6→0.7（**+16.7%**）、中性下限未动、无坍缩。

### M5e 四模式对照 + 混合方案（回响 × 潮汐）

- **目的**：验证两套方案正交可叠加；LLM-Judge 公平对比。
- **四模式对照**（`对照结果\四模式_20260809_053333.json`，5 提示，Qwen2.5-1.5B）：

| 模式 | 熵 | 情感命中率 | 重复率 |
|---|---|---|---|
| 裸 | 1.3563 | 0.1784 | 0.0 |
| 潮汐 | 1.3287 | 0.1846 | 0.0 |
| 回响 | 1.5831（+0.227） | 0.206 | 0.0 |
| **混合** | 1.4509（+0.095） | 0.2001（+0.022） | 0.0 |

- **LLM-Judge（30 样本公平对比，60 配对）**：裸 win_rate 0.1833/rating 0.733 → **混合（λ=0.08, 倍率=6）0.2167/0.740（+18.2%）**；混合（λ=0.10, 倍率=8）0.225 但为过注入（20 样本口径）。
- **EmoCharacter 混合**：一致性识别率 0.7（+16.7%）、毒舌损友净区分度 +0.30、爱撒娇小女儿 +0.425（角色特异性显著）。
- **结论**：混合方案公平同样本胜率 +18.2%（远超 10% 目标）；参数敏感性确认最优 λ=0.08 × 倍率=6，过注入退化。

### M5f AI 腔三通道抑制（v4）

- **诊断**：裸模型 57% 回复含 AI 腔（"作为/我是/助手/模型"），是裁判判 AI 的主因；单 token 抑制会被近义绕过，强度过高产生谐音怪词。
- **v4 三通道**：① 首 token 黑名单（×6 强压）；② decode 级过滤（首 token 扫 top-300 候选，AI 腔开头 -inf）；③ 短语感知（近 3 token 构成 AI 腔前缀抑制 ×3）。
- **LLM-Judge 全量 30 样本（60 配对）**：

| 模式 | win_rate | rating | 提升 |
|---|---|---|---|
| 裸 | 0.1833 | 0.733 | — |
| 潮汐 v3（AI抑制2.0） | 0.2000 | 0.753 | +9% |
| 潮汐 v4.1（AI抑制4.0） | 0.2333 | 0.747 | **+27%** |
| **混合 v4.2（λ0.08×倍率6 + AI抑制4.0）** | **0.3500** | 0.767 | **+91%** ✓ |

- **EmoCharacter 混合 v4.2**（`评测结果\EmoCharacter_潮汐.json`）：一致性识别率 **0.8**（裸 0.6，+33%）、真实一致性 0.956、匹配 fidelity 0.87、中性下限 0.72——AI 腔抑制未损害情感能力，反而因"更像角色"提升识别率。
- **强度扫描**（30 条）：0.0→13/30 命中；4.0→2/30（v4 后）；6.0/8.0 饱和不降且产生谐音怪词 → 最优 4.0。

### M5g 横向多模型（多模型泛化，20 样本同口径）

- **目的**：验证潮汐/混合跨模型可用性（Qwen2.5-1.5B / Qwen2.5-3B / Qwen3-1.7B，LLM-Judge 40 配对/模型）。

| 目标模型 | 裸 | 潮汐v4 | Δ潮汐 | 混合v4.2 | Δ混合 |
|---|---|---|---|---|---|
| Qwen2.5-1.5B | 0.200 | 0.275 | **+37.5%** | 0.375 | **+87.5%** |
| Qwen2.5-3B | 0.300 | 0.400 | **+33%** | 0.400 | +33% |
| Qwen3-1.7B | 0.575 | 0.550 | -4% | 崩溃（钩子不兼容） | — |

- **结论**：潮汐单模式跨模型可用（Qwen2.5 系 +33~37%，Qwen3 持平-4%）；混合限 Qwen2 系（Qwen3ForCausalLM 下回响注入产生噪声→重复崩溃）；增益与基础能力成反比；20 样本混合 +87.5% 与 30 样本 +91% 一致 → 方案稳定非运气。

### M5h / M5i 定向优化（v6–v8）

- **诊断（60 样本实测）**：混合输出仍有 ~10% 样本身份暴露（"我是大型语言处理系统/数字人"），回复 60+ 字长文（真人中位 20 字）。
- **v6 修复**：身份暴露硬拦截（decode 级开启器+身份名词紧邻 -inf）、兜底清理 + 定向拒绝采样（--身份拒绝）、句子边界硬停止（2 句即停）+ 最小长度（v6.2）。**v7 外挂**：gentle_v2 LoRA（温柔陪伴适配器）转口语化陪伴腔。
- **v8 三个新模块**：① 人设系统提示（口语化/短句/不自我介绍/不客服话术/不讲大道理，最大增益 +0.13~0.17）；② 身份拦截 v6.3（开启器窗口扩为尾部 10 字，绕行名词补全）；③ 多候选自选（--自选N，人味评分选最优）。
- **实测（LLM-Judge，8bit 裁判 / bf16 手动裁判同口径）**：

| 60-opt N30 | 混合 v6 + LoRA | 0.3500 | +31% |
| 60-opt N30 | 3B 混合 v6 | 0.4667 | — |

## 指标口径说明

- **语义熵**：生成序列逐 token softmax 分布熵均值（与 P1/P2 同源）；潮汐/混合模式要求熵不退化（≥ 裸 95%）。
- **重复率**：token 级 n-gram 重复比例；潮汐乘性重加权数学上有界，批实验中重复率 0 或接近 0，在线退化兜底（熵<0.6 或重复攀升→α×0.5，连续 3 次→α=0）保证任何模型不掉线。
- **情感命中率**：生成 token 中命中情感词库（cnsenti 同源 + NRC 精简）的比例；对照结果早期版本口径 0.03~0.18（词集不同），四模式/评测口径以"锚点库词集+cnsenti"或"情感 token 表"为准，跨批次对比需注意词集差异。
- **LLM-Judge win_rate**：AI vs 真人盲评胜率——30/60 条真人中文对话样本，7B 裁判对"目标模型回复 vs 真人回复"配对 AB 盲评（AB 对调双份投票消除位置偏差），win_rate = 目标模型胜过的配对 / 总配对（每样本 2 配对）。M5e 为 30 样本 60 配对，M5g 为 20 样本 40 配对，M5h/M5i 为 30 或 60 样本（N30/N60 命名，120 配对）。
- **EmoCharacter**：10 角色×4 轮，指标 = 匹配 fidelity（角色设定下情感保真度）、错配 fidelity、净区分度（匹配-错配）、真实一致性、一致性识别率（二选一识别）、中性下限 fidelity（中性提示下不被污染）。
- **HEART-BENCH(FEEL)**：7B 裁判对行为决策给共情分 0–1，综合 = (accuracy + empathy + consistency)/3。
- **HeartBench**：官方 296 条多轮心理咨询对话抽样，7B 裁判按官方 rubric 逐条 0/1 打分 + norm_score（0–100）。
- **TuringBench（中文体系）**：TF-IDF(1-2gram)+LR 训练"真人 vs AI"检测器留出测试，human_likeness = 1 − 被判为 AI 的比例。
