# Tasks — 一体化全流程 AI 应用

> 工作目录：`j:\最后版本！`｜语言：Python 3.10 + FastAPI + Web 前端｜约束：仅 NVIDIA CUDA，不支持 AMD

## 任务列表

- [x] Task 1: 项目骨架 + 配置系统 + 一键启动
  - [ ] 1.1 建立分层目录：`配置/`、`核心引擎/`、`前端/`、`数据/`（上传/分割片段/打标结果/日记/微调数据包/微调输出/模型库）、`测试/`、`发行版/`
  - [ ] 1.2 全局配置 JSON（所有模块输入/输出/格式/时间自定义项，含默认值与注释）
  - [ ] 1.3 `核心引擎/主服务.py`：FastAPI 应用骨架，静态文件挂载，健康检查接口
  - [ ] 1.4 `启动.py`：依赖检查（Python 版本/缺失包提示安装命令）→ 启动 uvicorn → 自动打开浏览器
  - [ ] 1.5 `requirements.txt`（torch/transformers/peft/bitsandbytes/fastapi/uvicorn/modelscope/cnsenti 等，清华镜像注释）

- [x] Task 2: 硬件检测与设备适配
  - [ ] 2.1 `核心引擎/硬件检测.py`：CUDA 可用性/版本/GPU 型号/驱动版本，显存总量与可用量，系统内存
  - [ ] 2.2 显存预估：按参数量 + 量化档位（fp16/4bit）预估推理与微调所需显存，判定"可推理/可微调/不可运行"
  - [ ] 2.3 明确检测 AMD（无 CUDA 且为 AMD）并给出"不支持 AMD"提示
  - [ ] 2.4 自动下载缺失依赖的引导（打印安装命令，不静默执行）

- [x] Task 3: 模型管理
  - [ ] 3.1 本地模型扫描：遍历模型库目录，读取 config.json（参数量/架构/量化档位），登记到模型库索引
  - [ ] 3.2 在线下载：镜像源可选（魔搭 ModelScope / 其他），模型 ID + 量化档位选择，断点续传，下载进度回调
  - [ ] 3.3 性能评估：加载模型跑一次生成（冒烟提示词），输出显存占用/生成速度/能否推理/能否微调报告

- [ ] Task 4: 数据预处理（输入 → 话题分割 → ASR）
  - [ ] 4.1 上传与清洗：视频/音频/文本三种输入，格式校验，去噪/去重/编码统一
  - [ ] 4.2 ASR 音频转文本：调用用户配置的全模态模型（具音频解码器），批量转写、断点续转，输出含时间戳的结构化文本
  - [ ] 4.3 话题分割：基于转写文本做语义分段（聚类/分段点检测），输出片段列表（话题摘要+时长+起始时间）
  - [ ] 4.4 分割预览接口：返回片段边界，支持人工微调边界后重存

- [x] Task 5: 打标引擎
  - [x] 5.1 复用 `f:\打标` 打标能力：对每个片段自动打标（情感维度/内容标签/风格）
  - [x] 5.2 人工复核界面/接口：修改标签、确认
  - [x] 5.3 微调数据包导出：JSON/JSONL（instruction/response 或对话格式 + 标签），可一键送入微调模块

- [x] Task 6: 日记生成（全新板块）
  - [x] 6.1 教师对话封装：连接本地大模型（用户配置，如 30B 千问）多轮对话接口
  - [x] 6.2 人设引导：用户填写角色人设 → 教师模型据此规划人生时间线（起始年龄 7 岁起）
  - [x] 6.3 超长期日记生成：逐年龄段/逐年生成数百~数千字日记，结合打标数据与音视频画面目录（画面描述/转录摘要注入上下文）
  - [x] 6.4 日记审阅：人工修改、补充、确认；生成参数（起始年龄/篇数/字数/风格）可配置
  - [x] 6.5 日记落盘到 `数据\日记\`，并可作为微调数据源（结构化、无乱码）

- [x] Task 7: 身份微调可行性验证
  - [ ] 7.1 设计小样本身份微调实验（"你是真人"类指令 + 自然口语语料），在可跑通的小模型上微调
  - [ ] 7.2 评估：微调前后生成样例对比（是否更像真人、是否出现格式退化/乱码），输出《身份微调可行性报告.md》
  - [ ] 7.3 依据结论设置身份维度默认建议（推荐/实验性标注）

- [x] Task 8: 微调引擎（三维度）
  - [x] 8.1 架构自动适配：识别模型（Qwen2.5/Qwen3 等）与思考能力（Qwen3 think 标记），选择 chat 模板与训练策略
  - [x] 8.2 LoRA/QLoRA 选择：按显存预估自动选 fp16 LoRA 或 4bit QLoRA（可手动覆盖）
  - [x] 8.3 三维度数据混合：情感（打标）/记忆（日记）/身份（真人文本）各维度可勾选，记录数据占比
  - [x] 8.4 文本结构化与乱码防护：统一编码、清洗控制字符、训练样例校验
  - [x] 8.5 训练执行：TrainingArguments（epochs/lr 等可配置）、日志、断点、产物落盘 `数据\微调输出\`
  - [x] 8.6 模型组织：一角色一模型（1:1）与三维合一单模型两种模式；单模型多记忆时前端标注"不推荐"+ 警告弹窗

- [x] Task 9: 推理架构（V / V1）
  - [x] 9.1 V1 架构：复用 `semantic_echo` 回响池 + 采样处理器，简单回响注入
  - [x] 9.2 V 通用架构：语义回响 + LoRA + RAG + 记忆四层，按需激活与优雅回退
  - [x] 9.3 参数定制：λ/γ/τ 自动推荐（扫描表/公式/架构族因子）或用户自定义
  - [x] 9.4 记忆外挂：持久化记忆文件读写，跨会话生效
  - [x] 9.5 加载微调产出模型（适配器/定制模型）作为基座或附加层，推理指标输出（语义熵/重复率/情感命中率/耗时/显存）

- [x] Task 10: 达标评估
