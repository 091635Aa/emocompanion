## 二、技术体系一句话速览

"EmoCompanion"是一套 **面向本地部署大语言模型（LLM）的、无需训练的解码期情感注入体系**。其核心理念是"情感不是对模型的改造，而是对模型已有能力的唤醒与引导"——通过在 logits 空间、注意力缓存、嵌入向量等**正交表征空间**施加最小化偏置，让模型自发产出符合角色人格与情感状态的表达。

- **离线准备**：PE 层从 6951 条打标数据提取 ≤10MB 的角色包
- **在线注入**：P1.5 统一调度 + P3/P4/P5 多通道注入 + P2.5 去 AI 腔
- **导演层**：P6（TAD/PIS/OQC）三层调度 + 五层正交空间 + 身份硬拦截
- **核心竞争力**：零训练、≤10MB 角色包、指针级热切换、μs 级额外开销、CPU 可跑
