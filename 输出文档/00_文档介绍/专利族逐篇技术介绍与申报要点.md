## P15 · 面向多层情感注入的运行时自适应强度调度方法

| 项 | 内容 |
|----|------|
| **技术问题** | 多层情感注入的层间强度协调困难：固定参数不适应动态场景，一键归零破坏人格连续性，RL 调参成本不可接受 |
| **核心技术** | ① 跨模型兼容参数 λ=λ_base×λ_arch×λ_quant；② β 效果曲线标定（0.4~1.4 保真度平坦 83-85%）；③ 实时监控熵/重复率/潮汐/复杂度；④ 五级优先级规则引擎（熔断>熵抑制>重复抑制>潮汐>复杂度） |
| **创新点** | INT4 量化补偿因子 0.75；会话潮汐因子（正弦周期）感知对话节奏；连续 3 次异常→裸采样熔断 |
| **权利要求** | 独立权利要求 1（6 步方法）+ 从属 2-9 + 装置权利要求 10-11 + 存储介质 12 |
| **实验证据** | 人格消失率 12%→3%；单步调度 <50μs；对比：固定参数/简单阈值/本方法 |
| **申报亮点** | "调度器"类方法专利，可单独申报也可作为系统部件，授权前景较好 |

## P25 · 数据驱动的解码期双向 token 概率调制方法（去 AI 腔）

| 项 | 内容 |
|----|------|
| **技术问题** | AI 腔（"首先/总的来说/值得注意的是"）损害自然度；后处理治标、清洗成本高、提示词不稳定、单向抑制表达贫化 |
| **核心技术** | ① 正例词袋 boost（per10k≥2.0，w=min(0.9, per10k/40)）；② 空泛词抑制表（1.2 强度）；③ 多 token 短语前缀匹配→末 token 调制（不碰首 token）；④ 滑动窗口管理 |
| **创新点** | "轻增强、重抑制"非对称策略（实验证明最强效）；数据驱动免人工定义；短语级处理 |
| **权利要求** | 独立权利要求 1（9 步）+ 从属 2-6 + 装置 11 + 存储介质 12 |
| **实验证据** | 四组对照（base/A/B-mild/B-strong/C-mild/C-strong）；C-mild 保真度 74%、AI 腔率 35%→15%；strong 反而劣化 |
| **申报亮点** | 与 P15 的"L1 指纹层"复用同一套技术，可在 P15 系统中作为子特征引用 |

## P3 · 基于情感锚点向量的解码期 logits 空间定向偏置注入方法

| 项 | 内容 |
|----|------|
| **技术问题** | 微调贵/遗忘/不可热切换；提示词约束弱/粒度粗；中间层适配器侵入性强 |
| **核心技术** | ① 6 个情感锚点向量（种子词嵌入均值）；② 静态打分表 S∈R^{V×K}（3.6MB）；③ `logits[w]+=β·tanh(S[w]·v_target/T)`；④ 对比提示角色向量提取（CPE）；⑤ 逐层判别力扫描选最优注入层 |
| **创新点** | tanh 硬上限防 logits 坍缩（有界偏置）；对比提示自动提角色向量；最优注入层 L35/36 发现 |
| **权利要求** | 独立权利要求 1（S101-S105 五步）+ 从属 2-10 |
| **实验证据** | 8 模型跨尺寸泛化；重复率 0.169→0.149；chat 设置诚实标注局限 |
| **申报亮点** | 体系基石专利，全谱系引用频次最高，**推荐优先申报** |

## P4 · 基于注意力缓存选择性缩放的情感感知 KV 调制方法（KVM）

| 项 | 内容 |
|----|------|
| **技术问题** | KV 缓存无情感语义感知；注意力操控缺情感维度；隐层注入显存/成本高 |
| **核心技术** | ① 情感门控函数 g(p)=clip(|s_p·v_eff|,0,1)；② Key 向量 in-place 缩放 K[p]*=1+κ·g(p)（κ=0.3）；③ 与 P3 双通道协同 |
| **创新点** | 零额外显存（in-place）；首次在 Key 向量层面做情感调制；实证发现"单通道有害、双通道增益" |
| **权利要求** | 独立权利要求 1（S401-S406）+ 从属 2-10 |
| **实验证据** | 双通道 win_rate 0.2667 全场最高；注意力熵 3.2→2.1（过度集中需 P3 补偿）；延迟 0.8ms |
| **申报亮点** | 与 P3 组成"组合发明"，协同效果有实验支撑，授权时"预料不到的技术效果"论证力强 |

## P5 · 基于动态状态向量的角色感知融合解码期情感注入方法（超融合）

| 项 | 内容 |
|----|------|
| **技术问题** | 静态 v_target 无上下文感知；角色人格与用户情感割裂；OOV 覆盖不足 |
| **核心技术** | ① 动态用户状态向量 v_dyn（最近 M token 时间加权）；② v_eff=norm((1-γ)v_角色+γ v_dyn)（γ=0.3）；③ DMR 稠密重加权补 OOV；④ P1.5 参数贯穿 |
| **创新点** | 角色稳定+动态适配的加权平衡；DSA 自参照情感加强循环；DMR 稠密/稀疏互补 |
| **权利要求** | 独立权利要求 1（S301-S305）+ 从属 2-9 |
| **实验证据** | 三通道综合持平 84；诚实标注边际收益递减、暂不启用 |
| **申报亮点** | 作为 P3 的从属改进可并入，也可独立构成"动态情感向量合成"方法 |

## P6 · 多通道协同的解码期情感导演调度方法及系统（EDD）

| 项 | 内容 |
|----|------|
| **技术问题** | 多通道缺全局编排、人格一致性无硬保障、AI 腔未治、无正例引导、空泛表达未抑制 |
| **核心技术** | ① 三层调度 TAD/PIS/OQC；② 五层正交空间 L0-L4；③ 角色感知锚定 v_target=0.7v_R+0.3v_U；④ **身份硬拦截**（OOC 检测+拦截句库，强度 2.5）；⑤ PersonaLayers 两阶段 logits 处理 |
| **创新点** | 五层正交空间形式化保证；身份硬拦截（多 token 短语续接+递减强度）；OOC 三级检测（自我认知/角色破裂/元讨论） |
| **权利要求** | 独立权利要求 1（S401-S405）+ 从属 2-12（最多） |
| **实验证据** | 综合得分 0.7046 全家族最高；泛化 +67%~+233%；AI 腔率最低 |
| **申报亮点** | 系统级专利（方法+系统），**权利要求布局最完整（12 项）**，可作为整套体系的统领专利 |

## PE · 基于情感特征谱的 AI 角色人格量化提取方法

| 项 | 内容 |
|----|------|
| **技术问题** | 角色提取依赖人工/训练；注入难热切换；无 vocab 级精细调控；角色包不标准难共享 |
| **核心技术** | ① 6951 条多维打标数据（人格/VAD/情感/声学）；② 6（或扩展 8）情感锚点；③ P3 偏置向量预计算；④ 口癖词袋+空泛抑制表；⑤ ≤10MB 角色包；⑥ 指针级热切换 |

| **权利要求** | 独立权利要求 1（8 步）+ 从属 2-8 + 装置 9-10 + 存储介质 11-12 |
| **实验证据** | 保真度 83% vs LoRA 88%（几乎持平）；推理 33 tok/s；切换 <1ms vs LoRA >2s |
| **申报亮点** | "数据→产品"端专利，与外围配套（角色包格式/热切换协议）可组合申报 |
