## 摘要

## 三、创新性检索验证（逐件比对最接近现有技术）

### 3.1 P3（锚点回响注入 · logits 空间偏置）

**检索到的现有技术：**
- [CN119721126A](https://patentimages.storage.googleapis.com/fe/db/fc/f469efbeb66b95/CN119721126A.pdf) 大语言模型性格塑造方法（北京邮电大学，2025.02）：训练"性格向量生成器"（神经网络）产出性格调整向量，注入注意力层之间——**需要训练**。
- [arXiv 2601.10960](https://arxiv.org/html/2601.10960v1)：SWAI——利用语料统计（z-normalized log-odds）构建 token 分数表，在 logits 层做写作风格 steering——**统计分表+logits 偏置方向接近**，但用于"写作复杂度/正式度/毒性"，且无情感锚点、无 tanh 有界化、无对比提示角色向量。
- [MS Semantic Kernel 博客](https://devblogs.microsoft.com/semantic-kernel/guest-post-crafting-unique-ai-personas-harnessing-the-power-of-logit-bias-in-large-language-models/)：直接用 OpenAI logit_bias 做 persona——**无表构建、无锚点、无 tanh**，仅手工 token 加噪。
- [arXiv 2510.23650](https://arxiv.org/html/2510.23650v1)：logits 层语义感知干预去偏——用途为 debiasing，非情感注入。

**区别特征（P3 独有）：**
1. 情感锚点向量 = 种子词嵌入均值（语义锚定，非统计频率）；
2. `β·tanh(S·v_target/T)` 的 tanh **硬上限有界化**防坍缩（麦克风对比：现有一律无界加噪）；
3. 对比提示（CPE）自动提取角色方向向量；
4. 静态打分表 O(1) 查表 + 最优注入层扫描（含 Qwen3-4B L35/36 具体发现）。

**初步判定**：独立权利要求 1 与任何单篇现有技术均不构成"同样的发明"；新颖性（A26.2）无碍。创造性（A22.3）需重点强调"锚点向量+tanh 有界+对比提示"组合的**预料不到的技术效果**（防坍缩 + 跨模型泛化）。**风险等级：中**。

---

### 3.2 P4（KV 情感共振 · 注意力缓存 Key 缩放）

**检索到的现有技术：**
- [arXiv 2605.06225](https://arxiv.org/html/2605.06225v1) Memory Inception：潜空间 KV Cache 操纵（memory bank 注入）用于 steering LLM——**领域最接近**（KV cache manipulation for steering），但机制为"记忆槽注入"，非情感门控 Key 缩放，且面向长上下文压缩。
- [arXiv 2410.12876](https://www.arxiv.org/pdf/2410.12876) Attention-Gate：KV cache eviction（驱逐）——**驱逐**非缩放。
- [arXiv 2508.04257](https://arxiv.org/pdf/2508.04257) KVSink、[arXiv 2506.03762](https://arxiv.org/pdf/2506.03762) AhaKV：KV 量化/驱逐优化——目的为压缩与效率，非情感调制。

**区别特征（P4 独有）：**
1. **情感门控函数** g(p)=clip(|s_p·v_eff|,0,1) 识别情感相关位置（现有技术无情感维度门控）；
2. Key 向量 **in-place 选择性放大**（κ∈[0,1.3]）而非驱逐/量化；
3. **零额外显存**声明 + 与 P3 logits 偏置的"双通道协同"（有 win_rate 0.2667 实验）。

**初步判定**：新颖性无碍；创造性需论证"情感门控+Key 缩放"与"KV 压缩/驱逐"类现有技术属于**不同发明构思**，且双通道协同效果超出预期。**风险等级：中低（若审查员引用 Memory Inception 类文献，需技术澄清）**。

---

### 3.3 P15（自适应强度调度）

**检索到的现有技术：**
- [CN119248289A](https://patentimages.storage.googleapis.com/e2/e2/47/a4ddc492023ca4/CN119248289A.pdf) 层次化自适应代码生成（哈工大深圳）：基于 logits 熵选择解码层——使用熵指标，但目标为代码生成选层，非"多层情感注入强度调度"。
- [GitHub Recync](https://github.com/metaSATOKEN/Recync_framework)：解码失效实时监控与干预——目的为安全约束。

**区别特征（P15 独有）：**
1. 跨模型兼容 λ=λ_base×λ_arch×λ_quant（隐藏维/架构族/量化补偿）三元归一化；
2. β 效果曲线标定确定安全工作区间（INT4 下 0.4-1.4 平坦 83-85%）；
3. 四维监控含**会话潮汐因子**（sin 周期函数）与输入复杂度；
4. 五级优先级规则引擎 + 连续 3 次异常熔断（渐降级而非一刀切）。

**初步判定**：新颖性无碍；创造性关注点在于"面向多层情感注入的调度"属新领域应用 + 量化补偿因子具技术意义。**风险等级：中**。

---

### 3.4 P25（去 AI 腔 · 双向 token 调制）

**检索到的现有技术：**
- SWAI（同上，[arXiv 2601.10960](https://arxiv.org/html/2601.10960v1)）：统计 token 分数表的 logits 风格 steering——**频率表方向最接近**。
- TextHumanizer / 各类"去 AI 味"工具：**均为后处理替换**，不作用于解码概率。
- 微软 Semantic Kernel persona 博客 / OpenAI logit_bias：token 级 logits 加噪。

**区别特征（P25 独有）：**
1. **双向**调制（正例 boost + 空泛抑制同框）且经对照实验证明协同优于单向（74 vs 73）；
2. 多 token 短语**前缀匹配→末 token 调制**（不碰首 token）——短语级处理，现有技术无；
3. 滑动窗口 + **数据驱动阈值**（per10k≥2.0、权重 min(0.9, per10k/40)）；
4. 抑制强度 1.2 的实验选定（含"strong 有害"负例证据）。

**初步判定**：新颖性无碍；创造性需强调"双向+短语前缀匹配+首 token 保护"组合，与 SWAI 的单向统计表（z-normalized log-odds 全体施加）相比有实质区别。**风险等级：中**。

---

### 3.5 PE（角色特征谱提取 · 角色包）

**检索到的现有技术：**
- [CN119721126A](https://patentimages.storage.googleapis.com/fe/db/fc/f469efbeb66b95/CN119721126A.pdf)（北邮）：性格调整向量——**需训练生成器**，不构成角色包。
- Persona Vectors（[arXiv 2507.21509](https://arxiv.org/pdf/2507.21509v1)，Anthropic）：对比提示在**激活空间**提取 persona 向量——非生成 data→角色包流程，且作用空间不同（残差流 vs logits 偏置表）。

**区别特征（PE 独有）：**
1. 完整"打标数据→锚点→vocab 偏置→≤10MB 角色包"**离线提取管线**；
2. 8 维情感向量表 + 口癖词袋 + 空泛抑制表的多组件角色包格式；
3. **指针级热切换**（<1ms）+ 标准化打包；
4. 纯 CPU、无训练。

**初步判定**：新创性隔离度较好。**风险等级：低-中**。

---

### 3.6 P5（超融合动态注入）

**检索到的现有技术：**
- [BILLY](https://arxiv.org/html/2510.10157v1)（NTU/UT）：激活空间 persona 向量**融合**（echo 创意生成）——融合思想接近，但为"多静态 persona 融合"，无动态语境分量。
- Persona Vectors 系列：均为静态方向向量。
- 动态情感强度调节类（Chen et al. 2023 Dynamic Sentiment Modulation）：调节强度非方向。

**区别特征（P5 独有）：**
1. **静态角色向量 + 动态用户状态向量**（每步从生成序列时间加权合成 v_dyn）的**方向级**融合 `v_eff=norm((1-γ)v_R+γv_D)`；
2. 自参照回路（DSA）：模型观测自身输出形成情感加强循环；
3. DMR 稠密重加权补 OOV + P1.5 参数贯穿。

**初步判定**：新颖性无碍；创造性较好（动态语境方向合成 + DMR 未见先例）。**风险等级：低-中**。

---

### 3.7 P6（情感导演调度系统）

**检索到的现有技术：**
- 系统级：未见与"三层调度（TAD/PIS/OQC）+ 五层正交空间 + 身份硬拦截"完整组合一致的现有方案。
- 单件组件：Recync（监控干预）、Guardrails（运行时过滤）、OOC 检测（角色扮演工程实践）、去 AI 腔（后处理）——组件均存在，但**组装成解码期多通道导演系统**的组合未见公开。
- notion：Container 级思想（oops抑制感叹）等放松。

**区别特征（P6 独有）：**
1. TAD/PIS/OQC 三层调度闭环 + PersonaLayers 两阶段 logits 处理器；
2. 五层正交空间（L0-L4）+ 角色感知锚定（0.7:0.3）；
3. **身份硬拦截**：OOC 三类检测 + 拦截句库 + 强度 2.5 多 token 短语续接。

**初步判定**：系统级组合专利，新颖性较稳固；创造性依赖"组合 + 特定（身份硬拦截）特征"的协同论证与 0.7046 等实验支持。**风险等级：低-中**。

## 六、对专利文件的修改建议（提升授权率）
