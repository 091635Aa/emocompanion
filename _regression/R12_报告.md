## 2. 覆盖明细（R12）

打标_RPG/业务逻辑层/结果解析.py 为纯逻辑模块（仅 json/re/stdlib），一次性纳入回归：
- **JSON 提取三兜底**：直接解析 → markdown 围栏 → `{}` 裁剪；非字符串/空文本返回 None。
- **数组字段清洗**：去重保序、过滤空白与非法项、非列表归空。
- **解析契约**：类型用素材信息兜底、元数据字段合并、置信度保留。
- **严格校验**：非 JSON / 缺必填字段 / 数组字段非数组 / 置信度非数字 → 全部抛 `ValueError` 且错误信息含原文片段。
- **置信度越界收敛**：>1 收敛到 1。

这层确保了「LLM 输出的不稳定文本 → 结构化字段」的健壮性，为 30B 服务解析失败时的诊断提供基线。
