## 2. 覆盖明细（R20）

`06_Qwen3TTS外挂/serve/tts_engine.py` 顶层仅依赖 stdlib（torch 惰性），**直接 import 真模块**离线验证：

- **EMOTION_VOCAB**：≥6 情感、键唯一、`[emotion]X[/emotion]` 自洽、兜底 `平静` 在词表。
- **`_compose_text`**：干净文本 strip、**绝不塞情感标签**（本引擎 tokenizer 无情感 token 的设计契约）。
- **`make_schedule`**：按句切分 + 情感分配——`list` 逐句给定（全指定不触发懒加载）、`dict` 局部覆盖、无标点单句、list 短于句数回落自动不炸。为让 `from emo_detect import detect_emotion` 可解析，测试把 serve 目录加入 `sys.path`。
- **`_check_paths`**：全部就绪不抛；缺 Base/情感外挂/角色音色 embedding 即抛 `TTSUnavailable` 且错误逐项列出。
- **`list_adapter_names`**：SR 24000、voice+emotion 双路、情感清单与词表一致。
