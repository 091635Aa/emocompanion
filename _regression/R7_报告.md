## 4. R7-B · 音频 RVC / SVC / VCS / TTS 族扫描

### 4.1 关键事实：本地变声实现缺失
扫描 `voice_clone_work/`、`定制音色/`、`tts_studio`、`Qwen3RapSynth`、`06_Qwen3TTS外挂`：
- **RVC**：无 `rmvpe/faiss/index` 推理链路脚本。
- **SVC / SV-VITS / VITS**：无 argmax-flow / diffusion 转换实现。
- **VCS**：无独立 vocoder 模块；语音合成走 **DashScope / qwen 云端 API**（`语音合成.py`、`synthesize.py`、`合成_emotion.py`）。

> 结论：工作区把「音色克隆/变声」整体外部化到云端 API，本地只有 TTS 标签/指令/韵律逻辑可离线单测。

### 4.2 本轮新增离线回归（test_x_speech_common.py，11 断言）
- `标准化标签`：中文标签 `[悲伤]→[sad]` 映射契约。
- `应用发音纠正`：长词优先替换、空表/空条目、拼音 `<phoneme>` 包裹。
- 图片等比缩放纯算术：超长边缩到限制、比例保持、极小图保护。

### 4.3 理论平移（云端→可测）
将 ETD 文本侧的「情感标签词表 + 注入」方法论平移为 **TTS 富标签注入**：`[sad]`/`<phoneme>` 作为情感承载面，与 06 外挂的 `emotion_ref/rate` 校准空间对接，形成一条「文本标签 → 语音指令 → 韵律回测」的可离线验证链路。

## 5. R7-C · 机器人模型族盘点 + 理论平移

扫描结论：工作区**无常驻具身/机器人模型**，最接近的控制面是：
- `锚点回响/目标决策器.py`：`v_target = 0.7·v_角色 + 0.3·v_用户` 行为决策（纯函数）。
- `打标_RPG/业务逻辑层/推理引擎.py`：图像输入编码（图传/图像理解载体）。

理论平移思路（写入本轮只做设计、不落线）：
- 将「目标决策器」的双源权重融合推广为**机器人行为决策器**：`行为 = f(角色基调, 环境状态, 指令)`，复用去AI腔/身份拦截的基类约束，保证输出身份一致。
- 将「图像等比缩放 + data URL 编码」复用为机器人视觉输入的预处理前置（已纳入离线回归验证）。
