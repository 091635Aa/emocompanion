## 2. R11-1 · librosa 依赖入集

先前因缺 librosa，`eval/metrics.py` 的 `f0_tracking` / `onset_beat_error`、`injector.apply_f0_contour` 无法离线复算。本轮成功安装 librosa 1.0.0（含 numba/llvmlite 全家），补齐后：

- `onset_beat_error`：构造拍网格脉冲 wav，实测对拍误差 < 0.25s。
- `f0_tracking`：220Hz 纯音，比对 mean_f0=220 的 LinePlan 目标，RMSE < 50Hz。

这使"生成质量客观指标"整链可在 CPU 上离线复核，为后续参考文本闭环校准提供可回归基数。

## 3. R11-2 · TTS 基座纯逻辑（免模型/torch）
