## 2. R9-1 · 身份键漂移护栏（关键决策记录）

**勘察结论**：`情感导演解码器.py` 与 `base_decoding_controller.py` 的 AI腔词表
身份键**完全重叠（重叠率 1.0）且权重一致**，但情感导演更全（含 P6/P6.1 扩展键：
"我没有情感/我专注于/准确的信息"等）。

**为什么不直接合并两表**：
- base 是 R6 建立的共享底座，消费方（情感共振/超融合/混合锚点等解码器）在 base 之上工作；
- 强行为 base 换成情感导演的扩展集，会**静默改变全部 base 消费者的抑制行为**，且当前无 GPU 无法量化侧证；
- 盲合有"同名不同权"风险。

**已落地护栏**：新增 10 个身份键（AI/助手/人工智能/模型/智能/作为一个/作为一名/机器人/程序/model）
的**权重一致性断言** — 两处必须同权；任何一方单独改权即红灯。扩展集差异保留，留待有 GPU 轮次做收敛级联。

## 4. R9-3 · RapSynth 客观指标回归

`eval/metrics.py` 中纯 numpy 指标函数率先离线化（librosa 依赖的 `f0_tracking`/`onset_beat_error` 暂不入集）：
- `beat_alignment_error`：on-beat 归 0、半拍偏 0.25、空 onset 归 0。
- `bpm_drift`：匹配归 0、双倍 BPM 得 0.5（相对期望）、单点归 0。
- `rhyme_hit` / `_end_char`：押韵命中率、末汉字提取、全押/半押/单行边界。
- `energy_contrast`：合成"矿音+强音"wav，重音段对比 >1。
