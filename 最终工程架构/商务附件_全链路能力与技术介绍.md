## 一、核心引擎：语义回响 V3（通用推理期情感增强引擎）

**一句话**：不训练、不改权重、零参数的推理期情感增强引擎，回收模型生成时被 softmax 丢弃的 token 嵌入作为「情感底色」持续注入，让小模型在情感表达 / 人味维度反超大模型。

**定位**：通用引擎架构——不绑定任何特定模型、场景或业务，任意 decoder-only 模型输入 hidden_dim 即自动获得最优注入参数（λ/γ/τ），即插即用。

### 核心实测结果（Qwen2.5-1.5B-Instruct 原版基座、未微调、同种子 42、严格 AB 对照）

| 基准 | 裸 1.5B | 挂载语义回响 | 结果 |
|---|---|---|---|
| TuringBench 人似度 | 0.2333 | **0.4667** | 翻倍 |
| EmoCharacter 情感保真 | 0.8750 | **0.8863** | 反超 |
| HeartBench 中文人味 | 0.4055 | **0.4130** | 反超 |
| HEART-BENCH 人格推理 | 0.4884 | **0.5367** | 反超 +10% |
| LLM-as-Judge 盲评 | 0.6900 | 0.6333 | 接近打平 |

- **4/5 基准反超**，被判为 AI 的比例从 77% 降至 37%
- **长上下文稳定**：λ 步数衰减，2048 tokens 生成全程熵 2.4~5.3、重复率≈0（固定方案 1024 步后坍缩复读至 0.98）
- **全模型自适应**：参数扫描表（0.5B/1.5B/3B/7B 实测最优）命中偏差 0%，公式兜底全部 <30%

### 四层集成框架（推理框架.py）

动态策略 v2（情感密度自动降 τ/升 λ）+ RAG + LoRA + 回响，任意组合开关。

## 二、全链路技术栈（从数据到产品的完整交付能力）

### 1. 数据打标（多模态情感打标流水线）
- 视频/音频分割 → 情感分析 → 标签评估与奖励 → 自动产出微调训练集
- 并行调度、实时状态看板、验收看板、稳定性守护、存储监控迁移
- 已实际完成大规模视频语料情感打标并产出微调训练集

### 2. 模型训练 / 微调
- SFT 与 LoRA 全流程实战（基于 LLaMA-Factory 等框架）
- 已产出情感 LoRA 适配器：emotion_v1 / emotion_3B / emotion_qwen3_4B / emotion_qwen3_4B_think / emotion_7B / gentle_v2
- 数据集构建、训练、评估、推理测试闭环

### 3. RAG 知识库（向量检索增强）
- ChromaDB / FAISS 向量库 + BGE-M3 嵌入模型
- 模型问答引用知识、不脱轨，可扩展游戏世界观 / 角色设定知识库

### 4. 超长期记忆系统（跨会话）
- 按情感维度 + 字符 n-gram 相似度加权检索
- 历史对话写入独立记忆文件（防并发写坏），注入下一轮生成
- 长期陪伴不断线、人设连贯

### 5. 推理优化（语义回响引擎）
- 参数自动匹配（自适应匹配.py）：扫描表 + 公式兜底
- 动态策略 v2：情感密度 > 阈值时自动降 τ / 升 λ
- λ 步数衰减：长上下文不坍缩

### 6. 智能体与语音
- 已交付完整智能体应用「缘圆智能体」：实时语音合成、音色克隆（定制音色全流程）、实时通话 / 视频通话、桌面端应用（pywebview 内置浏览器）
- 可直接复用于 AI 角色语音与陪伴场景

### 7. 生产级 API 服务（API 服务/）
- FastAPI 双协议：自定义协议 /api/v1/* + OpenAI 兼容 /v1/*
- 模型管理 / 下载 / 加载 / 卸载 / 生成 / 打标 / 测试 / 监控 / 记忆 / 开关 / 控制面板（三套 Web 面板）
- 模型加载后自动冒烟 + 全链路测试，CUDA 预热防崩溃
- 支持 AMD MI300X 环境启动

### 8. 数据闭环（持续迭代）
- 全流程运行记录 → 打标任务 → 定制模型训练 → 再挂引擎
